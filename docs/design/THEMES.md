# THEMES.md — Theme System & Color-Psychology Design Spec

> Owner: Architect. Decision: CONTEXT D17. Data: `config/themes.json` (generated by `scripts/design/derive-themes.mjs` from `src/image/theme/*.png`). Types: `schemas.ts` §12a. Implementation tasks: ROADMAP M4-01b.

---

## 1. Goals

1. **Settings → Theme** lets the user pick one of **18 themes**, each derived from a palette image in `src/image/theme/`, with **light, dark and follow-system** modes.
2. Every theme is designed around **color psychology** (each one carries a mood, a rationale and recommended activities, shown in the picker), so users can match the interface to the work they are doing (focus, finance review, ideation, night work…).
3. **Accessibility is non-negotiable:** every theme/mode pair meets WCAG 2.2 AA (body text ≥ 7:1 — AAA, muted text ≥ 4.5:1, button labels ≥ 4.5:1, focus/accent graphics ≥ 3:1). Contrast is computed and enforced by the derivation tool and re-checked by a unit test.
4. Switching theme is **instant, with no flash on startup** and no component changes — components only use semantic tokens.

## 2. Color-psychology principles applied

| Principle | How it is applied |
|---|---|
| **Blue → trust, calm, concentration** | Default light theme *Arctic Focus* and default dark theme *Midnight Focus* are blue: the app is used for long coding/analysis sessions. |
| **Low arousal for long sessions** | Backgrounds are near-neutral tints (OKLCH chroma ≤ 0.02) of the palette's lightest color; saturation is reserved for interactive elements so attention goes to actions, not chrome. |
| **Warm hues → energy, approachability** | Warm palettes (Sherbet, Peach Cream, Autumn Ember, Honey Sand) are recommended for chat and brainstorming, not for dense data review. |
| **Green → balance, growth** | Deep Forest / Spring Grove; when the brand hue is green, the *success* status color is shifted to teal so "brand" and "success" are never confused. |
| **Purple → creativity** | Royal Ink is recommended for ideation and image generation. |
| **Neutral grey → minimal distraction** | Winter Stone is the "focus mode" theme (presentations, screen sharing). |
| **Dark modes reduce glare at night** | Every theme ships a dark variant; dark backgrounds are tinted (never pure `#000`) to reduce halation and eye strain. |
| **Meaning never by color alone** | Status (success/warning/danger/info) always pairs color with an icon and text label; charts pair colors with labels/legends and distinct dash patterns where series > 4. |
| **Money semantics stay stable across themes** | Profit/margin ≥ 0 uses `success`, negative uses `danger`, regardless of theme; VND secondary line uses `textMuted`. |

## 3. Token derivation algorithm (implemented in `scripts/design/derive-themes.mjs`)

All math in **OKLCH** (perceptually uniform). Contrast is WCAG 2.x relative luminance.

1. **Roles from palette:** `brand` = most chromatic color; `accent` = next chromatic color whose hue differs ≥ 30° from brand (else second most chromatic); `darkest` / `lightest` by OKLCH L.
2. **Light variant:** `bg` = lightest palette color if L ≥ 0.94, else a tinted neutral (L 0.975); `surface` slightly lighter, `surfaceAlt` slightly darker, `border` L 0.86. `text` = darkest palette color if it reaches 7:1 on bg/surface/surfaceAlt, else a dark tint of its hue pushed to 7:1. `textMuted` ≥ 4.5:1 on surfaceAlt. `primary` = brand darkened until white label ≥ 4.5:1. `accent` darkened until ≥ 3:1 on bg.
3. **Dark variant:** `bg` = darkest palette color if L ≤ 0.26, else tinted near-black (L 0.18) in the darkest hue; surfaces step +0.04 L; `text` light tint ≥ 7:1; `primary` = brand lightened until ≥ 4.5:1 on surface; `primaryFg` = bg if ≥ 4.5:1 on primary else near-black.
4. **Status colors:** conventional hues (success 145°, warning 75°, danger 25°, info 250°), shifted when within 25° of the brand hue; lightness adjusted to ≥ 4.5:1 on surface.
5. **Chart series:** primary, accent, then the palette colors adjusted to ≥ 3:1 on surface; max 6, de-duplicated.
6. The tool **fails** if any check below its threshold; measured ratios are stored in `tokens.contrast`.

To add a theme: drop a 4-color palette PNG into `src/image/theme/`, add an entry to `THEME_META` (id, name, mood, psychology, recommendedFor), run `node scripts/design/derive-themes.mjs`, commit both files.

## 5. Runtime implementation spec (for Codex, M4-01b)

1. **Tokens as CSS variables.** `apps/desktop/src/theme/apply-theme.ts` writes every `ThemeTokens` field to `document.documentElement.style` as `--color-<kebab>` (e.g. `--color-surface-alt`, `--color-chart-1..6`), and sets `data-theme="<id>"`, `data-mode="light|dark"`.
2. **Tailwind v4 mapping** in `src/index.css`: `@theme { --color-bg: var(--color-bg); … }` so utilities like `bg-surface text-text border-border` exist. **Raw hex / Tailwind palette colors (`bg-blue-500`) are forbidden in components** — enforce with an ESLint `no-restricted-syntax` rule on className string literals matching Tailwind default palette names, and a test that greps `apps/desktop/src/**/*.tsx` for `#[0-9a-f]{3,6}`.
3. **No flash on startup:** the catalog JSON is bundled (static import of `config/themes.json`). The last applied `{themeId, mode}` is cached in `localStorage` and applied by an inline script in `index.html` before React mounts; the sidecar `settings.ui` remains the source of truth and overrides the cache once loaded.
4. **Mode resolution:** `mode = system` → `matchMedia('(prefers-color-scheme: dark)')` listener chooses the theme's `light` or `dark` tokens live.
5. **Transitions:** 150 ms `background-color, color, border-color` transition on theme change; disabled under `prefers-reduced-motion`.
6. **Validation:** UI loads the catalog through a zod schema (UI exception to "no zod in UI" because it is a build-time asset); unknown `themeId` falls back to `defaultLight`/`defaultDark`.
7. **Charts** (Recharts) read series colors from `--color-chart-n`; status chips from `--color-success|warning|danger|info`.
8. **Monaco editor / VS Code diff** in the Code tab: register a Monaco theme generated from tokens (`bg`, `text`, `surfaceAlt` for line highlight, `primary` for cursor, `accent` for selection at 30 % alpha).

## 6. Settings → Theme screen (UX spec)

```
Settings ▸ Theme
┌───────────────────────────────────────────────────────────────────────────┐
│ Mode:  ( System )  ( Light )  ( Dark )                     [Reset default]│
│ Filter: [All] [Focus] [Calm] [Warm] [Creative] [Dark-native]              │
│ ┌──────────────┐ ┌──────────────┐ ┌──────────────┐ ┌──────────────┐       │
│ │▓▓▓▓░░░░▒▒▒▒██│ │▓▓▓▓░░░░▒▒▒▒██│ │ ...          │ │ ...          │       │
│ │ mini preview │ │ mini preview │ │              │ │              │       │
│ │Arctic Focus ✓│ │Midnight Focus│ │ Deep Forest  │ │ Harbor       │       │
│ │Calm·focused  │ │Deep·quiet    │ │ Balanced     │ │ Stable       │       │
│ │ ⓘ            │ │ ⓘ            │ │ ⓘ            │ │ ⓘ            │       │
│ └──────────────┘ └──────────────┘ └──────────────┘ └──────────────┘       │
│ … 18 cards, responsive grid (min card width 180 px)                        │
│                                                                           │
│ Live preview panel: chat bubble, primary button, P&L card (USD/VND),       │
│ status chips, mini chart — rendered with the hovered/selected theme.       │
└───────────────────────────────────────────────────────────────────────────┘
```

- Card = 4-band palette strip + mini UI preview (bg, surface, primary button, text line) in the **current mode**, theme name, mood; ⓘ opens a popover with `psychology` and `recommendedFor`.
- **Hover = preview** (applies tokens to the preview panel only); **click = apply** globally and persist via `settings.update({ ui: { themeId } })`.
- Filters map to `recommendedFor` / mood keywords: Focus (arctic-focus, midnight-focus, winter-stone, lemon-sky), Calm (deep-forest, blush-lavender, vintage-dawn, espresso, peach-cream), Warm (sherbet, honey-sand, autumn-ember, candy-floss, berry-dusk, summer-meadow), Creative (royal-ink, berry-dusk, sherbet), Dark-native (midnight-focus, deep-forest).
- Keyboard: grid is a radiogroup (arrow keys move, Enter/Space apply); selected card has `aria-checked` and a visible focus ring (`focusRing`).
- Selected theme also shown in Settings summary and the status bar tooltip.
