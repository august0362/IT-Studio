# Task files

One file per ROADMAP task: `<ID>.md` (e.g. `M1-02.md`), written by the Architect using the template in `../ROLES.md` §1.1, created just before the task starts.
Codex appends `## Result` (or `## Blocked`); QA appends `## Fix round 1` when needed.

Completed task files are moved under `archive/`, grouped by milestone or work type. Active and future tasks stay in this folder.
