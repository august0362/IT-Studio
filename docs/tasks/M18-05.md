# M18-05 — Remote editor: Monaco, diff before save, conflict dialog, undo

Milestone: M18 · Depends on: M18-02, M18-04 · Role: Implementer · Size L · **Deps pre-installed** (Monaco present)
Requirements: FR-FS-08, D27

## Scope
`apps/desktop/src/features/servers/files/{RemoteEditor.tsx,SaveDiffDialog.tsx,ConflictDialog.tsx,language-for-file.ts}` (+ tests), reuse the Monaco theme bridge from M4-01b, i18n en/vi.

## Requirements
1. `language-for-file.ts` (pure): `.env*` → `ini`-like (`properties`), `*.yml|yaml` → yaml, `*.json` → json, `Dockerfile*` → dockerfile, `nginx.conf`/`*.conf` → `ini` fallback, `*.sh` → shell, `*.ps1` → powershell, `*.md` → markdown, else plaintext.
2. Editor opens content from `sftp.read`; dirty indicator; Ctrl+S → *Save* → `SaveDiffDialog` (Monaco diff original vs edited, read-only) → *Confirm save* → `sftp.write` with `baseSha256`, `eol`, `trailingNewline`, `backup: true`; success toast shows backup path; new hash becomes the base.
3. `CONFLICT` → `ConflictDialog`: *Reload (discard mine)*, *Compare* (diff remote-now vs mine), *Overwrite* (re-issues write with the current remote hash — backup still taken).
4. *Undo last save* → confirm → `sftp.undo` → reload.
5. Leaving with unsaved changes asks for confirmation.

## Tests
`language-for-file` table; component tests: save flow shows diff before write, conflict choices, undo, unsaved-changes guard. E2E `TC-M18-030` (written): edit `docker-compose.yml` on the fake server → diff → save → backup exists → undo restores.
