# M1-03 — Rust shell: spawn, relay, supervise the sidecar

Milestone: M1 · Depends on: M0-04 · Role: Implementer (ROLES §1.3) · **Deps pre-installed** (Cargo deps below already in `Cargo.toml` and fetched; run cargo with `--offline` — the sandbox cannot reach crates.io; no npm changes)

## Goal
The Tauri app spawns the Node sidecar, relays NDJSON lines both ways as a dumb pipe, restarts it on crash with backoff, and shuts it down gracefully — exposing nothing else to the webview.

## Requirements
1. Module layout: `src/sidecar/mod.rs` (Supervisor), `src/sidecar/spawn.rs` (command resolution), `src/sidecar/line_codec.rs` (NDJSON framing), `src/commands.rs`, `src/lib.rs` (wiring).
2. **Spawn (dev):** `node --import tsx <repo>/apps/sidecar/src/main.ts`; resolve repo root from `CARGO_MANIFEST_DIR` at compile time in debug builds; release builds use a placeholder path function returning an error "packaged sidecar not implemented (M9)". Env: `ITSTUDIO_DATA_DIR` = Tauri `app_data_dir()` (create it), `ITSTUDIO_LOG_LEVEL` = `info`. On Windows set `CREATE_NO_WINDOW` creation flag.
3. **Relay:** Tauri command `sidecar_send(line: String) -> Result<(), String>`: reject lines > 8 MiB or containing `\n`; write `line + "\n"` to stdin. Each stdout line → `app.emit("sidecar://message", line)` (string payload, unparsed). Stderr lines → Rust log at the level found in the pino JSON `level` field if parseable, else `info`.
4. **Ready gate:** track whether a line containing `"method":"system.ready"` has been seen since the last (re)start; expose command `sidecar_status() -> { running: bool, ready: bool, restarts: u32 }` and emit `sidecar://status` on every change.
5. **Supervision:** on unexpected exit, restart after 1 s, 2 s, 4 s, 8 s, 16 s (cap); more than 5 restarts within 5 minutes → stop and emit `sidecar://fatal` with `{ message, logDir }`.
6. **Shutdown:** on app exit request, send `{"jsonrpc":"2.0","id":0,"method":"system.shutdown","params":{}}`, wait up to 5 s for process exit, then kill. Must not trigger a restart.
7. **Security:** `capabilities/default.json` grants only `core:default` plus the two custom commands (`allow-sidecar-send`, `allow-sidecar-status` via a permissions file under `permissions/`). No shell/fs/http plugins. Keep the CSP from M0-04.
8. **Line codec:** handle partial reads and CRLF; strip a trailing `\r`; a single overlong line (> 8 MiB) is dropped with an error log, not a crash.
9. Unit tests (Rust, `cargo test`): line codec (split chunks, CRLF, overlong), restart backoff schedule + 5-in-5-min fatal rule (pure function over timestamps), send validation.

## Fix round 1 (QA)
Verified: cargo test 9/9 ✔, clippy ✔, permissions ✔, no unwrap on I/O ✔. One blocker:

1. **BLOCKER — app can never exit.** `src/lib.rs` `RunEvent::ExitRequested { api, .. }` calls `api.prevent_exit()` unconditionally. After graceful shutdown, `app.exit(0)` raises `ExitRequested` again (with `code: Some(0)`), which is prevented again → the window process hangs forever. Required change: destructure `code`; when `code.is_some()` (programmatic exit we triggered) do NOT call `prevent_exit()`; only intercept user-initiated exits (`code == None`). Also, if the supervisor is not managed (setup failed), allow exit immediately.
2. Extract the decision into a pure function, e.g. `fn should_intercept_exit(code: Option<i32>, shutdown_started: bool) -> bool`, and unit-test: (None,false)→true, (None,true)→true (still prevent, shutdown in progress), (Some(0),_)→false.

Re-run `cargo test --offline` and `cargo clippy --offline -- -D warnings`. Update `## Result`.
