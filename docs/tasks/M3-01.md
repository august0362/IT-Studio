# M3-01 — Cost & money domain (integer µUSD, USD/VND display)

Milestone: M3 · Depends on: schemas.ts only · Role: Implementer (ROLES §1.3) · **Deps pre-installed**

## Goal
All money math is exact integer µUSD and every amount shown to the user is a `MoneyDisplay` with USD on line 1 and VND on line 2 (D8), produced only by these pure functions.

## Read first
- `AGENTS.md`, CONTEXT D6–D8, `ARCHITECTURE.md` §6.1, §6.3, `schemas.ts` §0 (`MicroUsd`, `Vnd`), §6, `CONVENTIONS.md` §2.1

## Scope — files you may create/modify
- `apps/sidecar/src/domain/cost.ts`, `apps/sidecar/src/domain/money.ts`, tests next to them

## Requirements
1. `cost.ts`:
   - `computeTokenCost(usage: TokenUsage, price: PriceEntry): MicroUsd` = `ceil(((input − cached)·inPrice + cached·cachedPrice + output·outPrice) / 1_000_000)` using `bigint` internally to avoid overflow; `cached > input` → treat cached as input (clamp) — document.
   - `computeImageCost(count, price)`; missing `perImageMicroUsd` → 0 + flag.
   - `estimateRequestCost(promptChars, maxOutputTokens, price): MicroUsd` with prompt tokens ≈ `ceil(chars/4)`.
   - `findPrice(table, modelKey): PriceEntry | undefined`.
   - Constructors `microUsd(n)` / `vnd(n)` validating integer + range (`Number.isSafeInteger`); the only place besides validation/brand.ts allowed to brand (CONVENTIONS §2.1).
2. `money.ts`:
   - `toVnd(amount: MicroUsd, fx: FxRate): Vnd` = round-half-up(µUSD × rate / 1e6).
   - `formatUsd(µUSD)`: `$` + 4 decimals when |amount| < $1, else 2 decimals with `,` thousands; negative as `-$1.23`; zero `$0.00`.
   - `formatVnd(vnd)`: vi-VN grouping with `.` thousands, no decimals, suffix ` ₫` (e.g. `31.456 ₫`, `-1.200 ₫`) — implement deterministically (no reliance on ICU locale data being present).
   - `toMoneyDisplay(amount, fx): MoneyDisplay`; `sumMicroUsd(list)`; signed amounts supported for margin.
3. Pure: no Date, no I/O.

## Tests (property + example)
- Example table: Sonnet 5.5 prices from `config/pricing.seed.json` × known usage → exact µUSD; cached tokens path; ceil rounding of fractional µUSD.
- Large values (10^9 tokens) do not lose precision.
- Formatting table: 0, 0.0001, 0.99999, 1, 1234.5, −0.5, VND 0 / 999 / 1000 / 31456 / −1200.
- `toVnd` rounding half-up at .5.
- Coverage ≥ 95 % lines (domain threshold).
