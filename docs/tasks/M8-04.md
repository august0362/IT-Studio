## Scope
- `apps/desktop/src/features/gallery/**` (new) + tests, `apps/desktop/src/features/chat/MessageList.tsx` (image parts) + tests, `apps/desktop/src/features/settings/images/**` (new) + tests, `apps/desktop/src/shell/{MainNav,AppShell}.tsx` (enable the Gallery route — lazy), `apps/desktop/src/i18n/{en,vi}.json`
- `apps/desktop/src-tauri/tauri.conf.json` / `capabilities/**`: enable the asset protocol **scoped to `$APPDATA/com.itstudio.app/images/**` only** (no wider scope); CSP `img-src` adds the asset protocol origin only.
- If the UI needs the absolute image path, add an RPC `images.path({assetId})` → `{ path }` (additive schema + validator + 1 container line) that resolves only inside the images directory.

## Requirements
1. Chat: `image` parts render inline (lazy, max width, alt = revised prompt or prompt), click opens a lightbox; images never loaded from remote URLs.
2. Gallery tab (per project; "All projects" aggregate): grid of `ImageAsset` (thumbnail, prompt, revised prompt, provider, cost via `<Money>`, date), open in lightbox, "Open folder" (Tauri opener, images dir only), delete with `ConfirmDialog` → `images.delete`.
3. Settings → Images: **enable image generation** toggle (`settings.image.enabled`, default off, with a cost note), provider order list (keyboard reorder like the router ladder), provider key status hint linking to API Keys.
4. Keyboard accessible; en + vi strings.

## Tests
Components with a fake RPC client: image part render + lightbox, gallery grid / delete confirm / cancel, settings toggle + reorder; a static test that the asset-protocol scope in `tauri.conf.json` / capabilities is limited to the images directory.
