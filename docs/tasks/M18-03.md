# M18-03 — Upload / download with progress and cancel

Milestone: M18 · Depends on: M18-01 · Role: Implementer · Size M · **Deps pre-installed** (dialog plugin)
Requirements: FR-FS-06 · DD-V3-05

## Scope
`services/sftp/transfer-service.ts` (+ test), `src/types/schemas.ts` RPC `sftp.upload|download|cancelTransfer` + notification `sftp.progress`, validators, `container.ts`; desktop helper `apps/desktop/src/features/servers/files/useTransfers.ts` (+ test) using dialog `open`/`save`.

## Requirements
1. Local paths come only from the dialog (UI) and are validated in the sidecar: absolute Windows path, exists (upload) / parent exists (download), not a directory, not inside `%APPDATA%\com.itstudio.app` (protect app data), size ≤ 2 GB.
2. Upload to `remoteDir/basename(localPath)`; existing target without `overwrite` → `CONFLICT`; streaming via SFTP `fastPut`-like chunked writes to `<target>.itstudio-tmp` then rename (same atomicity rule as M18-02, no backup unless overwriting — then backup).
3. Download streams to `<localPath>.part` then renames; existing local file was confirmed by the OS save dialog.
4. Progress notifications ≤ 4/s per transfer, final `done`; cancel aborts and removes temp files on both sides.
5. Max 2 concurrent transfers per server (queue others).

## Tests
Fake SFTP: upload/download success (sizes 0, 1 B, 5 MB), overwrite rules, cancel mid-way cleans up, protected local path rejected, progress rate cap.
