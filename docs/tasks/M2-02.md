## Requirements
1. Use `@anthropic-ai/sdk` (`messages.create`, streaming via `messages.stream` or `stream: true`), client constructed per call with the passed `apiKey`, `maxRetries: 0` (the router owns retries), `timeout` = `req.timeoutMs`, `signal` forwarded. Base URL `https://api.anthropic.com`.
2. Mapping: `system` → top-level `system`; messages → Anthropic content blocks (text, image as base64 is out of scope → reject `image` parts with `bad_request`); tools → `tools[{name, description, input_schema}]`; `tool_use` blocks → `ToolCall` (`id`, `name`, `arguments`); `tool_result` parts → `tool_result` blocks. `responseFormat: 'json'` → append system instruction "Respond with a single JSON object only." (no prefill).
3. Usage: `inputTokens = input_tokens + cache_read_input_tokens + cache_creation_input_tokens`, `cachedInputTokens = cache_read_input_tokens`, `outputTokens = output_tokens` (missing fields → 0). Finish reason: `end_turn|stop_sequence → stop`, `max_tokens → length`, `tool_use → tool_calls`, `refusal → content_filter`.
4. Failure classification (ARCH §5.2): 429 `rate_limit_error` → `rate_limited` (+ `retry-after` header); 400/402 whose error message matches /credit balance|billing|quota/i → `quota_exhausted`; 401/403 → `auth`; other 400/404/413/422 → `bad_request`; 500/502/503/504/529 (`overloaded_error`) → `server_error`; no first byte within `timeoutMs` → `timeout`; network error → `server_error`; stream interrupted after ≥ 1 delta → failure with `billed: true`.
5. `listModels` → `GET /v1/models` ids.
6. Fixtures (JSON + SSE in Anthropic's real event format: `message_start`, `content_block_start/delta/stop`, `message_delta` with usage, `message_stop`) for every contract case. Run `runProviderContract('anthropic', …)`.
7. Messages surfaced in `ProviderFailure.message` must not include the raw response body beyond the provider's `error.type` + first 200 chars of `error.message`, and never the API key.
