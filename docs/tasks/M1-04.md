# M1-04 — UI RpcClient + React hooks

Milestone: M1 · Depends on: M1-03 · Role: Implementer (ROLES §1.3) · **Deps pre-installed** (`@tanstack/react-query`, `zustand`)

## Goal
React code calls the sidecar through one fully typed client — `rpc.call('settings.get', {})` is type-checked against `RpcMethodMap` — and subscribes to typed notifications, over the Tauri relay built in M1-03.

## Requirements
1. **Transport port** `ISidecarTransport { send(line: string): Promise<void>; onMessage(cb: (line: string) => void): () => void; onStatus(cb: (s: SidecarStatus) => void): () => void; onFatal(cb: (f: { message: string; logDir: string }) => void): () => void; status(): Promise<SidecarStatus> }` with `SidecarStatus = { running: boolean; ready: boolean; restarts: number }`.
   - `TauriTransport` uses `invoke('sidecar_send'|'sidecar_status')` and `listen('sidecar://message'|'sidecar://status'|'sidecar://fatal')`.
   - `FakeTransport` for tests.
2. **`RpcClient`:** `call<M extends RpcMethod>(method: M, params: RpcMethodMap[M]['params'], opts?: { timeoutMs?: number; signal?: AbortSignal }): Promise<RpcMethodMap[M]['result']>`; rejects with `RpcCallError` carrying `AppError` (from `error.data`) or a synthetic `AppError` (`INTERNAL` "sidecar restarted", `CANCELLED`, timeout → `PROVIDER_TIMEOUT`? **no** — use `INTERNAL` with message "request timed out"). Default timeout 30 s. Ids monotonically increasing. Incoming lines parsed with `JSON.parse` inside try/catch; malformed lines ignored + `console.warn` in dev only.
   - `on<N extends RpcNotificationName>(name: N, handler: (p: RpcNotificationMap[N]) => void): () => void`.
   - When status transitions `running:true → false` or `restarts` increments, all pending calls reject with "sidecar restarted".
   - Calls made while `ready=false` are queued until ready (max 100 queued; overflow rejects).
   - Note: the UI trusts the sidecar's payload shapes (same-process trust boundary, ARCH §3) — no zod in the UI.
3. **Hooks:** `useRpcQuery(method, params, options?)` (TanStack Query, key = `[method, params]`), `useRpcMutation(method)`, `useNotification(name, handler)` (stable subscription, cleans up), `useSidecarStatus()` (zustand store fed by transport status + fatal).
4. **`main.tsx`:** create a single `RpcClient` with `TauriTransport`, provide via React context + `QueryClientProvider`.

## Tests (vitest + jsdom, FakeTransport)

- `useRpcQuery` renders data; `useNotification` handler invoked and cleaned up on unmount.
- Type tests: wrong params for a method → `// @ts-expect-error` compiles.
