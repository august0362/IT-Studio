# WC-01 — Quick web chat: open ChatGPT / Gemini / Grok in the user's browser (Cốc Cốc etc.)

Milestone: WC (v1 addendum, D34) · Depends on: — · Role: Implementer (ROLES §1.3) · Size M · **Deps pre-installed** (no new dependencies)

## Goal
From IT Studio the owner opens the consumer web chats (chatgpt.com, gemini.google.com, grok.com, …) **in their own browser** — default **Cốc Cốc** when installed — so the browser's existing logins and extensions are used. A *Copy project brief* button puts a short project summary on the clipboard to paste into that chat. IT Studio does not read or automate those pages (D34): no scraping, no cost tracking for them.

## Contracts (add to `schemas.ts` exactly; `readonly` everywhere)
```ts
export type WebChatLinkId = Brand<string, 'WebChatLinkId'>;
export interface WebChatLink { readonly id: WebChatLinkId; readonly name: string; readonly url: string; readonly enabled: boolean }
export const WebChatBrowser = { DEFAULT: 'default', COCCOC: 'coccoc', CHROME: 'chrome', EDGE: 'edge', FIREFOX: 'firefox', CUSTOM: 'custom' } as const;
export type WebChatBrowser = (typeof WebChatBrowser)[keyof typeof WebChatBrowser];
export interface WebChatSettings {
  /** Browser used to open links. Default: coccoc when detected, else 'default' (system browser). */
  readonly browser: WebChatBrowser;
  /** Absolute path to a browser .exe; used only when browser = 'custom'. */
  readonly customBrowserPath: string | null;
  readonly links: readonly WebChatLink[];
}
// AppSettings: readonly webChat: WebChatSettings;
// RpcMethodMap:
'webchat.browsers': { params: Empty; result: readonly { readonly browser: WebChatBrowser; readonly installed: boolean; readonly path: string | null }[] };
'webchat.open': { params: { readonly linkId: WebChatLinkId }; result: { readonly opened: true; readonly browser: WebChatBrowser } };
'webchat.projectBrief': { params: { readonly projectId: ProjectId }; result: { readonly text: string } };
```

## Requirements
1. **Default links** (ids stable): ChatGPT `https://chatgpt.com/`, Gemini `https://gemini.google.com/app`, Grok `https://grok.com/`, Claude `https://claude.ai/new`, Google AI Studio `https://aistudio.google.com/`, Perplexity `https://www.perplexity.ai/` — all enabled.
2. **URL rules** (pure, `domain/web-chat.ts`): `https:` only, valid hostname (no IP literals, no credentials `user@`, no `localhost`), length ≤ 2 048; link name 1–40 chars; max 20 links; unique ids. Violations → `VALIDATION` with field details (settings update).
3. **Browser locator**: Cốc Cốc `%ProgramFiles%\CocCoc\Browser\Application\browser.exe`, `%ProgramFiles(x86)%\…`, `%LOCALAPPDATA%\CocCoc\Browser\Application\browser.exe`; Chrome `…\Google\Chrome\Application\chrome.exe` (same three roots); Edge `%ProgramFiles(x86)%\Microsoft\Edge\Application\msedge.exe` (+ `%ProgramFiles%`); Firefox `%ProgramFiles%\Mozilla Firefox\firefox.exe` (+ x86). First existing path wins. `custom` = `customBrowserPath`, must be absolute, end with `.exe`, exist.
4. **`webchat.open(linkId)`**: the UI passes only an id — the URL always comes from saved settings (the webview can never make the sidecar open an arbitrary URL). Link must exist and be enabled. Spawn via the process-runner port with `shell:false`, detached, stdio ignored, not awaited: `<browser.exe> <url>` (Chromium-based browsers reuse the running window and open a new tab). `default` (or chosen browser not installed → fall back to `default` and return `browser: 'default'`) = `explorer.exe <url>` (resolve `%WINDIR%\explorer.exe`). Spawn failure → `INTERNAL` with remediation "Choose another browser in Settings → Web chat". Never log the full URL query string.
5. **`webchat.projectBrief(projectId)`**: plain text, ≤ 4 000 chars, no file contents, no secrets: project name, then "Folder structure (depth 2):" with the tree from the existing project-context helper (reuse it; depth 2, max 150 lines, same ignore list), then a one-line instruction placeholder "My question: ". Unknown project → `NOT_FOUND`.
6. **Upgrade-safe settings (critical):** an existing settings row written by an older version has no `webChat`; loading it must **fill missing top-level sections from defaults before validation** (generic: for every top-level key of `defaults` missing in the stored object, use the default) — it must **not** fall into `recoverCorrupted` and reset the owner's settings. Add a regression test: stored v1 settings without `webChat` → loaded settings keep the stored router/budget/ui values and gain default `webChat`.
7. **Default browser choice** is computed at defaults-build time: `coccoc` if detected, else `default` (inject the locator into default-settings creation, or resolve lazily in the service when the stored value is the default — document the choice).
8. **UI — Chat header:** a *Web chat* button with a dropdown of enabled links (name + host), keyboard accessible (menu button pattern); selecting calls `webchat.open`; a toast "Opened in Cốc Cốc" (browser label from result). Menu footer items: *Copy project brief* (active project; clipboard via `navigator.clipboard.writeText`; toast "Copied") and *Edit links…* (navigates to the settings section).
9. **UI — Settings → Web chat:** browser select showing installed state from `webchat.browsers` (not-installed options disabled, label "(not installed)"); custom path text field when `custom`; links table: name, URL, enabled toggle, move up/down, delete; *Add link*; *Reset to defaults*; validation errors from the sidecar shown per field; save via `settings.update`.
10. All strings en + vi; theme tokens only; no raw HTML.
