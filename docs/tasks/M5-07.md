Milestone: M5 · Depends on: M5-05, M5-06, M4-01 · Role: Implementer (ROLES §1.3) · **Deps pre-installed**

## Goal
Manage the active project's knowledge base: add files or folders inside the project, watch ingestion progress, see indexed documents, re-index or delete them, try a query and see the retrieved chunks, and switch RAG on for a chat (ARCH §7, D4).

## Requirements
1. **Add sources:** one or more workspace-relative paths (files or folders) + optional tags → `rag.ingest`; sidecar `VALIDATION` errors (outside workspace etc.) shown inline with remediation. Disabled on "All projects".
2. **Progress** (`ingest-store.ts`, pure, 100 % branches): track jobs from `rag.progress` by id — status, processed/total (progress bar with text), no cost display (`IngestJob.cost` is raw µUSD and React must not format money; embedding cost is visible in the Cost & P&L tab); final status `indexed` / `failed` (with `ErrorPanel`), `skipped_unchanged` counted.
3. **Document table:** `rag.listDocuments` refreshed when a job finishes: title, format, chunks, embedding model, ingested date (locale date), tags; actions **Re-index** (calls `rag.ingest` with the document's source path relative to the workspace if derivable, else hidden) and **Delete** (in-app `ConfirmDialog` → `rag.deleteDocument`).
4. **Test query panel:** query text, topK (1–20, default `settings.rag.defaultTopK`), minScore (0–1, default from settings) → `rag.query`; results list title › section path, score (2 decimals), text excerpt (plain text, no markdown). Model-mismatch `VALIDATION` shows "Re-index required" with a button that re-ingests all documents.
5. **Chat integration:** in `ChatPage` a "Use knowledge" switch bound to `Conversation.ragEnabled` (`chat.setRagEnabled`); assistant `citation` parts render as numbered chips; clicking a chip opens a popover with title › section path and the chunk text (plain text).
6. Keyboard accessible; en + vi strings.

## Tests
