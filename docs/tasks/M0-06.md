# M0-06 — Test gate: Vitest projects + coverage thresholds

Milestone: M0 · Depends on: M0-04, M0-05 · Role: Implementer (ROLES §1.3)

## Goal
`npm test` runs every package's tests with one command, enforces coverage thresholds from CONVENTIONS §6, and resolves `@itstudio/schemas`.

## Read first
- `AGENTS.md`, `CONVENTIONS.md` §6, `ADR-0002` (Vitest `^5`)

## Scope — files you may create/modify
- `vitest.config.ts` (root), `apps/*/vitest.config.ts`
- root `package.json` (scripts + devDependencies), `package-lock.json`, `apps/*/package.json` (scripts/devDeps only)
- New test files: `apps/sidecar/src/main.test.ts`, `apps/desktop/src/App.test.tsx`, `apps/vscode-ext/src/extension.test.ts`
- `apps/desktop/src/test-setup.ts`

## Requirements
1. Dev deps: `vitest@^5`, `@vitest/coverage-v8@^5`, `@testing-library/react`, `@testing-library/jest-dom`, `jsdom` (desktop only), `msw` (root, for later tasks).
2. Root `vitest.config.ts` uses Vitest **projects** pointing to `apps/sidecar`, `apps/desktop`, `apps/vscode-ext`; each project resolves alias `@itstudio/schemas` → `src/types/schemas.ts`.
   - sidecar & vscode-ext: `environment: 'node'`; desktop: `environment: 'jsdom'`, setup file importing `@testing-library/jest-dom/vitest`.
3. Coverage (v8, root): include `apps/*/src/**`, exclude tests, `main.tsx`, `apps/vscode-ext/src/extension.ts` (VS Code API host-only), type-only files. Global thresholds: lines 70, functions 70, branches 60, statements 70. Per-glob thresholds: `apps/sidecar/src/domain/**` lines 90 (applies when files exist — must not fail while empty).
4. Tests:
   - sidecar: `describeSidecar()` returns string containing provider count = `Object.keys(ProviderId).length`.
   - desktop: renders `<App/>`, heading "IT Studio" visible, provider count text correct.
   - vscode-ext: test a pure helper — extract the status-bar label into `export function statusLabel(state: 'idle' | 'connected' | 'disconnected'): string` in `src/status.ts` (you may create it; `extension.ts` must use it) and test all 3 states.
5. Root scripts: `"test": "vitest run"`, `"test:watch": "vitest"`, `"coverage": "vitest run --coverage"`. Ensure the `test` script works with extra args (`npm test -- --reporter=json`).
6. Mocking `vscode` module is **not** required (only pure helpers are tested).
