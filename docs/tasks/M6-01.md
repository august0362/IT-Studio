# M6-01 — `resolveSafe` path guard + `IFileSystem` port

Milestone: M6 · Depends on: schemas.ts only · Role: Implementer (ROLES §1.3) · **Deps pre-installed** · Safety-critical module → **100 % branch coverage** (TESTING.md §4)

## Goal
Every workspace path the Worker touches goes through one function that makes path traversal and out-of-scope writes impossible (ARCH §9.1, D16).

## Read first
- `AGENTS.md`, `TESTING.md` §3–§4, `ARCHITECTURE.md` §9.1, §11 (path traversal row), `schemas.ts` §0 (`WorkspaceRelativePath`), §1 (`ErrorCode.PATH_OUTSIDE_WORKSPACE`)

## Scope — files you may create/modify
- `apps/sidecar/src/domain/path-guard.ts` (+ test), `apps/sidecar/src/ports/file-system.ts`, `apps/sidecar/src/infra/node-file-system.ts` (+ test), `apps/sidecar/src/infra/memory-file-system.ts`

## Requirements
1. `ports/file-system.ts`: `IFileSystem` with async `readFile`, `writeFile`, `rename`, `unlink`, `mkdir(recursive)`, `stat`, `realpath`, `exists`, `readdir`, `copyFile`, `fsync(path)`; all return `Result`. Node impl (`node:fs/promises`) + in-memory impl for tests (supports symlinks so escape cases are testable).
2. `domain/path-guard.ts` (pure part): `normalizeRelative(input: string): Result<WorkspaceRelativePath>` — reject: empty, absolute POSIX (`/x`), Windows drive (`C:`, `c:\\`), UNC (`\\\\server`, `//server`), any `..` segment after normalisation, NUL byte, reserved Windows names (`CON`, `NUL`, `COM1`…, case-insensitive, with or without extension), trailing dot/space segments, length > 1024; normalise `\\` → `/`, collapse `./` and duplicate slashes.
3. `isWithinAllowed(path, allowedPaths): boolean` — exact match or directory prefix on segment boundaries (`src/a` allows `src/a/b.ts`, not `src/ab.ts`).
4. `isForbidden(path)`: `.git/**`, `node_modules/**`, `.itstudio/**` (journal access goes through a separate explicit API) → true.
5. `resolveSafe(root, rel, allowedPaths, fs): Promise<Result<string>>` (I/O part): normalise → forbidden check → allowed check → join with absolute `root` → `realpath` of the deepest existing ancestor must stay inside `realpath(root)` (symlink escape) → returns absolute path. Errors: `PATH_OUTSIDE_WORKSPACE` with remediation; never include the raw input beyond 200 chars in messages.

## Tests (black-box corpus + white-box branches)
- Traversal corpus (≥ 40 cases): `../x`, `a/../../x`, `a/..\\..\\x`, `%2e%2e/x` (treated literally — must NOT be decoded, stays inside), `/etc/passwd`, `C:\\Windows`, `c:x`, `\\\\srv\\share`, `//srv/share`, `a\u0000b`, `CON`, `con.txt`, `aux/x`, `a/ .`, `a./b`, 1025-char path, unicode lookalikes (`．．/x` full-width dots — stay literal, inside), mixed separators.
- Allowed-prefix boundary cases (EP/BVA); forbidden dirs; symlink inside → allowed; symlink escaping root → rejected; root itself is a symlink → works.
- 100 % branch coverage of `path-guard.ts` (`--coverage.include`), stated in Result.
