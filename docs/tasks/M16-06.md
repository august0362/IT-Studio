## Requirements
1. `useServerWatch(serverIds)`: `server.watch` with a per-view id on mount and when `document.visibilityState === 'visible'`; `server.unwatch` on hidden/unmount; history fetched on mount for sparklines.
2. Card: RAM bar (warning ≥ 80, danger ≥ 90 — tokens `warning`/`danger`, plus text percentage), CPU sparkline 10 min (lightweight SVG or Recharts in the lazy chunk), Net ↑/↓ auto units (B/s → KB/s → MB/s, 1 decimal, 1024 base, labelled), top 3 disks + "+n more" popover, battery widget only when `battery != null` (icon + percent + state text), uptime humanised, `late` indicator.
3. Updates throttled to animation frames; no re-render of all cards per sample (memoised per server).
4. Alerts: toast for fired/resolved (with server name, metric, value), Alert center panel (last 100, clear), OS notification via plugin when `settings.monitoring.osNotifications` (request permission once; denied → setting note).
5. Accessibility: bars have `role="meter"` with aria values; colour never the only signal.

## Tests
Component tests: formatting tables (0 B/s, 1023, 1024, 1.5 MB/s), thresholds 79/80/89/90, battery hidden on null, watch/unwatch on visibility change (mock), throttling. E2E `TC-M16-030` (written): fake server scripted samples → card values update; hide tab → no samples requested.
