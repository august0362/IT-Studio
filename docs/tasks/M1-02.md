# M1-02 — Sidecar bootstrap: NDJSON stdio loop, RpcServer, EventBus, logger, container

Milestone: M1 · Depends on: M1-01 · Role: Implementer (ROLES §1.3) · **Deps pre-installed** (`pino`)

## Goal
The sidecar speaks JSON-RPC 2.0 over stdio exactly per ARCH §3, routes requests to typed handlers, pushes typed notifications, logs safely, and is fully unit-testable without a real process.

## Requirements
1. **Ports:** `IClock { now(): Date; monotonicMs(): number }`, `IIdGenerator { uuid(): string }` with real + fake impls.
2. **`infra/logger.ts`:** pino → stderr (fd 2) and rotating daily file `<ITSTUDIO_DATA_DIR>/logs/sidecar-YYYYMMDD.log` (keep 7). Redact paths: `*.apiKey`, `*.authorization`, `*.headers.authorization`, `*["x-api-key"]`, `*.token`. Export `createLogger(opts)`; never log to stdout.
3. **`rpc/line-transport.ts`:** reads stdin as UTF-8, splits on `\n`, tolerates CRLF and partial chunks, rejects lines > 8 MiB (respond -32700 with id null); `write(obj)` serialises one line to stdout through a single writer (no interleaving). Injectable streams for tests.
4. **`rpc/event-bus.ts`:** `EventBus<RpcNotificationMap>` with `publish<N>(name, params)` and `subscribe<N>(name, handler) → unsubscribe`. Typed: wrong payload = compile error.
5. **`rpc/rpc-server.ts`:** registry `register<M extends RpcMethod>(method, handler: (params: RpcMethodMap[M]['params'], ctx) => Promise<Result<RpcMethodMap[M]['result']>>)`. Pipeline: parse JSON (-32700) → envelope schema (-32600) → method known (-32601) → `rpcParamsSchemas[method]` (-32602 with `data` = VALIDATION AppError) → handler → `Result` ok → `result`; error → -32000 with `data: AppError`. Handler throws → -32000 `INTERNAL` (message generic, stack logged). Requests are processed concurrently; responses carry the request id. Forwards every EventBus notification as `RpcNotification`.
6. **`services/system-service.ts`:** `system.ping` → `{ version (from package.json), uptimeMs }`; `system.shutdown` → `{accepted:true}` then triggers graceful shutdown hook list (empty for now) and `process.exit(0)` within 5 s (exit injectable for tests).
7. **`container.ts`:** composition root building logger, clock, ids, bus, server, services; exports `createContainer(env)` (pure wiring, no side effects until `start()`).
8. **`main.ts`:** `createContainer(process.env).start()`; after start publish `system.ready` `{ version, recoveredTransactions: 0 }`. Unhandled rejections are logged (not crash) ; uncaught exceptions logged then exit 1 (Rust restarts).
9. **`domain/assert.ts`:** `assertNever(x: never): never`.

## Tests
- Transport: split chunks, CRLF, overlong line, multiple lines in one chunk.
- Server: each error code path (-32700, -32600, -32601, -32602, -32000 from Result, -32000 from throw); concurrent requests answered with correct ids; notification forwarding.
- Logger redaction: an object with `apiKey` logs `[Redacted]` (assert on captured stream).
- End-to-end in-process: fake stdin/stdout → `system.ping` → valid response; first line written is `system.ready`.
