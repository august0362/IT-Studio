# M14-01 — Facebook Page connect (Page token, validation, keychain)

Milestone: M14 · Depends on: M14-00 · Role: Implementer · Size M · **Deps pre-installed**
Requirements: FR-FB-01, FR-FB-06 · ARCH §17.6

## Scope
- `apps/sidecar/src/providers/channel/facebook/{graph-client.ts,facebook-connect-service.ts}` (+ tests), `src/types/schemas.ts` RPC `facebook.connect` + validator, `container.ts`
- Desktop: `apps/desktop/src/features/inbox/ConnectFacebookDialog.tsx` (+ test): Page id, Page token (password field, never echoed back), project select

## Requirements
1. Graph client via `IHttpClient`, base `https://graph.facebook.com/<graphVersion>`, token as `access_token` query param **only in the request, never logged** (extend redaction for URLs: strip query strings in logs).
2. Validate: `GET /{page-id}?fields=id,name` and `GET /{page-id}/conversations?limit=1`; map errors: code 190 → `CHANNEL_AUTH` ("Generate a new long-lived Page token"), 10/200/230 → `CHANNEL_AUTH` listing `pages_messaging`, `pages_read_engagement`, `pages_manage_metadata`; 4/17/32/613 → `CHANNEL_RATE_LIMITED`.
3. Store token in keychain `itstudio-channel/<accountId>`; account `displayName` = Page name; reconnect with the same Page id updates the token of the existing account.
4. Token value length 50–1 000 chars, no whitespace (else `VALIDATION`).
5. Test seam: with `ITSTUDIO_E2E=1` and `ITSTUDIO_E2E_GRAPH_BASE_URL` set, the Graph base URL is replaced (fake server for M14-QA); ignored otherwise.

## Tests
msw: success, each error code class, redaction of query strings in logs; component test (token field cleared after submit).
