# M9-06 — Isolated install smoke (replaces the clean-VM test, D33)

Milestone: M9 · Role: Implementer (ROLES §1.3) · **Deps pre-installed** · Effort: small

## Goal
Prove on this machine that the installed app is self-contained: it must start and work without the system Node.js, without the repository and without any `node_modules` outside the install directory.

## Scope
`scripts/build/install-smoke.ps1` (new), root `package.json` script `smoke:install` (scripts only), `docs/RUNNING.md` (install section).

## Requirements
1. Script steps: find the newest NSIS installer under `apps/desktop/src-tauri/target/release/bundle/nsis/` → silent install (`/S /D=<temp dir>`) → start the installed `itstudio-desktop.exe` with a **sanitised environment**: `PATH` reduced to `C:\Windows\System32;C:\Windows` (no Node, npm, Rust), `NODE_PATH` / `NODE_OPTIONS` removed, working directory = the install dir, and a temp copy of nothing from the repo.
2. Verify: the sidecar process is the bundled `itstudio-sidecar*.exe` (not `node.exe`), the newest sidecar log contains `"sidecar ready"` within 30 s, and the sidecar process has no handle / module loaded from the repository path or a `node_modules` outside the install dir (check `Get-Process -Module` paths of the sidecar).
3. Close the main window gracefully, verify app + sidecar exit within 5 s, silent uninstall, verify the install dir is gone. Print a PASS / FAIL table; exit non-zero on failure.
4. RUNNING.md: "Install IT Studio" section — run the NSIS installer, SmartScreen "More info → Run anyway" (unsigned, D33), where data lives, how to uninstall.

## Acceptance criteria
- [ ] `npm run lint` passes (script formatting); QA runs `npm run smoke:install` outside the sandbox (opens the app window). Do not run E2E.
