# M14-04 — Guide: `docs/guides/facebook-page-setup.md`

Milestone: M14 · Depends on: M14-01 · Role: **Architect** · Size S
Requirements: A-1, R-03

## Content
1. Prerequisites: the owner is an admin of the Page; a Meta developer account.
2. Create a Meta app (type Business), add the Messenger product, keep the app in **development mode** (works for Page admins/testers; explain when App Review would be needed).
3. Generate a Page access token with `pages_messaging`, `pages_read_engagement`, `pages_manage_metadata`; exchange for a **long-lived** token (steps with Graph API Explorer and the token debugger); note expiry behaviour.
4. In IT Studio: Inbox → Accounts → Connect Facebook Page → Page id + token + project.
5. The 24-hour rule, what *expired* drafts mean, and alternatives (Meta Business Suite).
6. Rate limits and what the app does.
7. Revoking access; where the token is stored (Windows Credential Manager `itstudio-channel/<id>`).
8. Troubleshooting: codes 190, 10/200, 613.
