# UX-06 — Theme round 2: more character (Codex owns the design)

Milestone: v1 owner acceptance feedback (2026-10-16) · **After UX-05 (landed)** · Role: Implementer **and designer** · Size M–L · Model: gpt-6.1-sol, effort high · **Broad scope inside `apps/desktop/src/**`, `config/themes.json`, `scripts/design/**`, `apps/desktop/index.html`, `docs/design/**`: do not stop for edits needed to meet a requirement — list them in Result**

## Owner verdict on UX-05

UX-05 is consistent and readable but still feels flat: there are no icons in the sidebar or on buttons, the page headers have no visual anchor, and empty pages are bare. Owner: keep UX-05, then give the app **more character** in a second round, with Codex deciding the style.

## Freedom and direction

Same creative freedom as UX-05; build on its token system rather than replacing it. Add personality without losing calm and readability. Ideas, not orders — choose what fits:

- **Iconography:** one coherent icon set for the sidebar, primary actions, settings sections, process kinds, empty states and status. Implement the icons as local inline SVG components. You may add **one** icon package (e.g. `lucide-react`) — justify it in Result, and it must tree-shake. Icons always come with text labels or `aria-label`.
- **Page headers:** title + subtitle + primary action + subtle accent (rule, gradient tint or illustration) — consistent across pages.
- **Empty states** for chat, projects, knowledge, gallery, processes, cost: small illustration or icon composition, one-line explanation, primary action.
- **Micro-interactions:** hover/press/focus states, list item hover, subtle entrance transitions, toast and dialog motion. Respect the motion setting and `prefers-reduced-motion`.
- **Sidebar:** icons + labels, active indicator, compact-collapse option (icons only, tooltips) remembered per user, a clear project context at the top.
- **Brand touch:** a simple IT Studio logomark in the sidebar header and on the about/empty screens (SVG, theme-aware).

## Hard constraints (unchanged from UX-05)

- AA contrast test stays green; no hard-coded colours outside tokens; Pipeline Studio/process viewer stay pure black.
- No behaviour changes; keep roles/labels/test ids.
- Performance: no heavy filters on lists.
- Vietnamese diacritics render correctly; fonts and icons are offline.

## Tests

- Icon components render with accessible names.
- The sidebar collapse persists.
- Empty states show their primary action.
- Motion is respected.
- Existing tests green.
