## Requirements
1. Dev deps (root): `eslint@^10`, `@eslint/js`, `typescript-eslint@^8.71`, `eslint-plugin-boundaries`, `eslint-plugin-react-hooks`, `globals`, `prettier`, `eslint-config-prettier`.
2. `eslint.config.js` (flat config, ESM; default export allowed for config files):
   - Ignore: `**/dist/**`, `**/target/**`, `**/node_modules/**`, `.npm-cache/**`, `apps/desktop/src-tauri/**`, `scripts/lint-fixtures/**` (fixtures are linted only by the self-test, see 5), `scripts/design/**`, `scripts/dev/**` (Architect tooling, not app code). Prettier also ignores `config/themes.json` (generated).
   - `tseslint.configs.strictTypeChecked` + `stylisticTypeChecked` with `parserOptions.projectService: true`.
   - Rules (error): `@typescript-eslint/no-explicit-any`, `@typescript-eslint/ban-ts-comment` (allow `ts-expect-error` with description ≥ 10 chars), `@typescript-eslint/consistent-type-imports`, `@typescript-eslint/switch-exhaustiveness-check`, `no-restricted-syntax` with selectors and messages for: `TSEnumDeclaration` ("Use as-const object + union (CONVENTIONS §2)"), `TSModuleDeclaration[kind!='global']` (namespaces), `ExportDefaultDeclaration`, `TSParameterProperty`.
   - `no-restricted-properties` / `no-restricted-syntax`: forbid `dangerouslySetInnerHTML` (JSXAttribute name), `innerHTML` assignment, `eval`, `new Function`.
   - Forbid `shell: true` property in object literals (`Property[key.name='shell'][value.value=true]`).
   - Overrides allowing default export: `**/*.config.{js,ts,mjs}`, `**/vite.config.ts`, `eslint.config.js`.
   - `eslint-plugin-boundaries` element types for `apps/sidecar/src/{rpc,services,domain,providers,infra,validation,scheduler,prompts}` with the dependency rules of CONVENTIONS §3.2 (domain imports nothing internal; services → domain + ports; rpc → services + validation; providers/infra → domain). Define them now even though folders are empty.
   - React hooks rules for `apps/desktop/src/**/*.tsx`.
   - `eslint-config-prettier` last.
3. Prettier: `printWidth 120`, `singleQuote true`, `trailingComma all`, `semi true`. Script `"format": "prettier --write ."` and `"format:check": "prettier --check ."` (ignore md, lockfiles, dist, target, src-tauri/gen).
4. `scripts/scan-secrets.mjs` (Node, no deps): scans git-tracked + untracked-not-ignored files (`git ls-files -co --exclude-standard`), skips binaries and `scripts/lint-fixtures/`, matches patterns: `sk-[A-Za-z0-9_-]{20,}`, `sk-ant-[A-Za-z0-9_-]{20,}`, `AIza[0-9A-Za-z_-]{35}`, `xai-[A-Za-z0-9]{20,}`, `gsk_[A-Za-z0-9]{20,}`, `r8_[A-Za-z0-9]{20,}`, `-----BEGIN (RSA |EC )?PRIVATE KEY-----`. Prints `path:line: pattern-name` (never the matched value) and exits 1 on any hit. Accepts optional file args (used by self-test).
5. `scripts/lint-fixtures/`: `bad-enum.ts`, `bad-any.ts`, `bad-default-export.ts`, `bad-html.tsx`, `bad-secret.txt` (fake key matching a pattern). Script `"lint:selftest"` that asserts each fixture **fails** (ESLint run with `--no-ignore` on the TS fixtures and scan-secrets on the txt) and exits 0 only if all fail as expected.
6. Root scripts: `"lint": "eslint . --max-warnings 0 && node scripts/scan-secrets.mjs"`, `"lint:selftest"` as above.
