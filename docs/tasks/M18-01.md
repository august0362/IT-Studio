# M18-01 — SftpService browse operations and remote path rules

Milestone: M18 · Depends on: M18-00 · Role: Implementer · Size M · **Deps pre-installed**
Requirements: FR-FS-01, FR-FS-05 · ARCH §21

## Scope
- `apps/sidecar/src/domain/remote-path.ts` (+ test), `services/sftp/sftp-service.ts` (+ test), `apps/sidecar/test/support/fake-sftp.ts` (per M18-00), `src/types/schemas.ts` RPC `sftp.list|stat|home|mkdir|rename|delete` + validators, `container.ts`
- integration `apps/sidecar/test/integration/sftp.test.ts`

## Requirements
1. `remote-path.ts` (pure): parse/normalise POSIX absolute paths (collapse `//`, `.`; resolve `..` lexically then reject if it escapes `/`), reject NUL and control chars, max 4 096 chars; Windows hosts: accept `/C:/x`, `C:\x`, `C:/x` → canonical `/C:/x`; `join`, `dirname`, `basename` helpers.
2. Service acquires SSH consumer `sftp` per operation batch (keeps the SFTP channel open 30 s after the last use).
3. `list`: entries sorted dirs first then name (locale-insensitive), `kind` via lstat (symlink shown as symlink; target not followed for listing), mode, size, mtime; hidden files included.
4. `home`: `realpath('.')`.
5. `delete`: file or **empty** directory only (non-empty → `VALIDATION` "remove contents first"); never recursive.
6. Errors mapped: no such file → `NOT_FOUND`, permission denied → `VALIDATION` "permission denied on server", others → `INTERNAL` with safe message.

## Tests
Path corpus (≥ 30 cases incl. Windows forms, `..` escape, unicode names); service against fake SFTP: list/stat/mkdir/rename/delete rules, Windows mode. Integration `TC-M18-001` browse via RPC.
