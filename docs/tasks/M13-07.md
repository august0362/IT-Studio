# M13-07 — Guide: `docs/guides/gmail-setup.md`

Milestone: M13 · Depends on: M13-01 · Role: **Architect** · Size S
Requirements: A-1 (SRS v2 §2.5), R-02

## Content (English, numbered steps, no screenshots required)
1. Create a Google Cloud project; enable the Gmail API.
2. OAuth consent screen: External, testing mode, add the owner's address as a test user; scopes `gmail.modify`, `gmail.send`, `openid`, `email`; explain the "unverified app" warning and why it is safe here (own client, own account).
3. Create OAuth client ID of type **Desktop app**; copy client id (and secret if shown).
4. In IT Studio: Inbox → Accounts → Connect Gmail → paste → browser consent → back to the app.
5. Command senders, `[ITS]` prefix rule, DKIM note (send commands from the same Gmail account).
6. Disconnect / revoke (Google Account → Security → Third-party access); token storage location (Windows Credential Manager, entry `itstudio-channel/<id>`).
7. Troubleshooting table: `invalid_grant` (testing-mode tokens expire after 7 days → reconnect), `redirect_uri_mismatch` (wrong client type), quota errors.
