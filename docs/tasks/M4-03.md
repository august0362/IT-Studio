### Schema additions (copy exactly)
```ts
export interface PriceRow {
  readonly entry: PriceEntry;
  readonly input: MoneyDisplay;
  readonly output: MoneyDisplay;
  readonly cachedInput: MoneyDisplay;
  readonly perImage?: MoneyDisplay;
  /** True when a manual override is active for this model. */
  readonly overridden: boolean;
}
'pricing.getRows': { params: Empty; result: { readonly table: PriceTable; readonly rows: readonly PriceRow[]; readonly stale: boolean } };
'pricing.overrideUsd': {
  params: { readonly modelKey: ModelKey; readonly inputPerMTokUsd: string; readonly outputPerMTokUsd: string; readonly cachedInputPerMTokUsd: string };
  result: PriceTable;
};
```
(`stale` = table older than 30 days, ARCH §6.2. USD strings: `^\d+(\.\d{1,6})?$`, parsed to µUSD in the sidecar with string/bigint arithmetic; then same behaviour as `pricing.override`.)

## Requirements
1. **Router:** ladder list sortable with dnd-kit (mouse **and** keyboard sensors; announcements i18n) → `router.updateConfig` with renumbered priorities; per-entry enable toggle; **Auto Fallback** switch (default ON, explanation text: OFF = you will be asked to choose); **Lock model** select (`lockedModelKey`, "None" = null); user-decision timeout (seconds, 10–300).
2. **Budget:** **Hard Stop** switch (`settings.update({budget:{hardStop}})`) with a warning text that paid calls will be blocked once a budget is exceeded; link to the Cost & P&L tab for budget limits.
3. **Pricing:** table from `pricing.getRows` (model, input / output / cached per 1M tokens via `<Money compact>`, origin, overridden badge); "stale" banner when `stale`; **Update prices** button → `pricing.refresh`, shows the `PriceUpdateRun` result (applied / no change / rejected with per-model Δ% table / fetch failed with `ErrorPanel`); disabled while running and when no project is active (D31 message); per-row **Override** dialog → `pricing.overrideUsd`; listen to `pricing.updated`.
4. **FX:** current rate (VND per USD, plain number formatting is fine — it is a rate, not money), source and as-of date; override input (positive number) → `fx.override`; "Clear override" → `fx.override({usdToVnd:null})`.
5. **VS Code:** auto-launch switch, `code` executable path (text, empty = auto-detect), show diff before validate, reveal changed files → `settings.update({vscode:…})`.
6. **Pipeline roles:** for PM / Coder / Reviewer an ordered multi-select of models from `models.list` (≥ 1 each) → `settings.update({pipeline:{roleAssignment}})`; validation commands list read-only with a note (editing comes later); `maxFixAttempts` shown read-only (= 1, D5).
7. Every form: optimistic disable while saving, sidecar errors via `ErrorPanel`, success toast via the existing notification hook; keyboard accessible; en + vi.
