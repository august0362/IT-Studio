# M13-02 — Gmail adapter: HTTP client, sync (history / list), MIME → text

Milestone: M13 · Depends on: M13-01 · Role: Implementer · Size L · **Deps pre-installed** (`mailparser`)
Requirements: FR-GM-03, FR-GM-04, FR-CH-04 · ARCH §17.5

## Scope
- `apps/sidecar/src/providers/channel/gmail/{gmail-client.ts,gmail-adapter.ts,mime-to-message.ts}` (+ tests), adapter registration in `container.ts`, `config/channels.json` zod validation, fixtures `apps/sidecar/test/fixtures/gmail/*.json|eml` (multipart/alternative, HTML-only, attachments, non-UTF-8 charset, Vietnamese subject encoded-word)
- Gmail adapter must pass the channel contract suite (M12-01)

## Requirements
1. Client via `IHttpClient`: bearer from auth service; 401 → refresh once and retry; 429/5xx → backoff 1 s/2 s/4 s honouring `Retry-After` (max 3 tries); other errors → classified `AppError` (`CHANNEL_AUTH`, `CHANNEL_RATE_LIMITED`, `INTERNAL`).
2. Sync: cursor = historyId. With cursor → `history.list(startHistoryId, historyTypes=messageAdded, labelId=INBOX)` paging; 404 → fall back as without cursor. Without cursor → `messages.list(q="newer_than:<syncWindowDays>d in:inbox", maxResults ≤ maxInitialMessages)`. New cursor = `users.getProfile().historyId` read **before** listing (no gap).
3. For each id `messages.get(format=raw)` → `mailparser` → from (address + name), subject, text (prefer text/plain; else HTML → plain helper), `receivedAt` from `internalDate`, `externalThreadId = threadId`, `externalMessageId = id`, meta: `messageIdHeader`, `references`, `authenticationResults`, attachment names. Skip messages sent by the account itself (SENT label).
4. Concurrency: max 4 parallel `messages.get`; abort via signal.
5. Test seam: when `ITSTUDIO_E2E=1` and `ITSTUDIO_E2E_GMAIL_BASE_URL` is set, Gmail **and** OAuth token/auth endpoints use that base URL (fake server in the L3/L4 harness, M13-QA); ignored otherwise.

## Tests
msw-based: first sync, incremental sync, 404 history fallback, 401 refresh, 429 retry-after, pagination; MIME fixtures → expected text; contract suite.
