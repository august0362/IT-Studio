# M5-03 — Embedding providers + same-dimension fallback dispatcher

Milestone: M5 · Depends on: M2-01, M3-02 · Role: Implementer (ROLES §1.3) · **Deps pre-installed** (`openai`, `@google/genai`)

## Goal
Turn text batches into vectors via OpenAI (`text-embedding-3-small`) or Gemini (`gemini-embedding-2`) at a fixed dimension (1536), with fallback between same-dimension models and metered cost (D4, ARCH §7.1, §7.3).

## Scope
- `apps/sidecar/src/ports/embedding-provider.ts`, `apps/sidecar/src/providers/embedding/{openai,google}.ts` (+ tests + fixtures), `apps/sidecar/src/services/embedding-dispatcher.ts` (+ test). **No `container.ts` changes** (wiring happens in M5-05).

## Requirements
1. `IEmbeddingProvider { id; embed(texts: readonly string[], { modelId, dimensions }, apiKey, signal) → Result<{ vectors: number[][]; inputTokens: number }, ProviderFailure> }`.
2. OpenAI: `embeddings.create({ model, input, dimensions })`, `maxRetries: 0`; Google: `models.embedContent` / batch with `outputDimensionality`; both classify failures exactly like the chat adapters (reuse `domain/failure.ts` mappings; 429/quota/auth/5xx/timeout).
3. Validate every returned vector length === requested dimensions (else `bad_request`-class internal error with clear message) and L2-normalise vectors (cosine-ready).
4. `EmbeddingDispatcher.embed(texts, { projectId, purpose: 'embedding' })`: splits into batches of `config.batchSize`, tries `config.modelKey` then `fallbackModelKeys` (only models whose configured dimension equals `config.dimensions`), retries transient failures with the shared backoff helper, loads API keys per attempt via `ISecretStore`, and emits the same internal completion event shape the ledger consumes (`RouterCompleted`-compatible: model, usage `{inputTokens, outputTokens:0, cachedInputTokens:0}`, purpose `embedding`) so cost is metered without ledger changes.
5. Empty input → empty result without calls; texts > model limit are the caller's problem (chunker sizes them) but guard with a clear error if a single text exceeds 8 000 estimated tokens.
