## Requirements
1. **Graph:** React Flow canvas from `workflow.graph` — nodes positioned by `layout.ts` (pure, deterministic: lanes ui / engine / data / pipeline / storage as rows, stable order within a lane), edges labelled with their `contract`; node shows label, status (`idle` / `active` / `error` / `disabled` — icon + text, not colour alone), in-flight count, 24 h calls / errors, cost `<Money compact>`; zoom / pan / fit-view controls; keyboard: Tab / arrow keys move between nodes, Enter opens the panel. Theme via CSS variables only (React Flow styles mapped to tokens).
2. **Live:** subscribe to `workflow.activity`; `workflow-store.ts` (pure, 100 % branches) applies batches — pulses the node, animates the edge (`edgeId`) for ~1.5 s, updates counters / status; throttle UI work to animation frames; refresh the graph every 30 s while visible (no polling while hidden).
3. **Panel (click a node):** *Now* (in-flight items with elapsed time), *Recent* (from `workflow.activity({moduleId})`, kind filter, "load more" with `before`), *Metrics 24 h* (calls, errors, p50 / p95 duration, cost), *Links in / out* (edge contracts + last summary), *Deep links* (open the chat conversation, the pipeline run in Code, the ingest job in Knowledge, the Cost tab).
4. **Projects:** per active project tab; "All projects" → `projectId: null` aggregate with project filter chips.
5. Summaries are displayed as plain text only.
