# M2-07 — `LlmRouter` service (I/O around the pure machine)

Milestone: M2 · Depends on: M2-05, M2-06, M1-06 · Role: Implementer (ROLES §1.3) · **Deps pre-installed**

## Goal
A single `LlmRouter.dispatch(LlmRequest)` that orders candidates, enforces eligibility, retries/backs off, falls back, opens circuits, supports cancel and mid-stream fallback, and emits `router.event`s — driven entirely by `domain/router-machine.ts`.

## Requirements
1. **Ordering:** `ladderOverride` → else (`lockedModelKey` then the ladder minus it) → else ladder by priority (enabled only). Filter by eligibility (M2-05); ineligible models are skipped and recorded as `RouterAttempt{outcome:'skipped'}`.
2. **Loop:** feed machine inputs from real events; execute effects: `check_budget` → `IBudgetGuard`; `dispatch` → load secret via `ISecretStore` (never cached beyond the call), call adapter `stream` or `complete` with `AbortController` combining caller cancel + per-attempt timeout; `wait` → injected `IClock`-based sleep (fake timers in tests); `emit_fallback` → `router.event{fallback}`; `request_user_decision` → delegate to `IFallbackDecider` port (implemented in M2-08; default impl rejects immediately with `FALLBACK_DECLINED`); `discard_partial` → notify stream consumer via `onReset()` callback.
3. **Circuit breaker** per model: `failureThreshold` consecutive fallback-trigger failures → open for `cooldownMs` (quota → `max(cooldownMs, 3_600_000)`), half-open single probe, close on success; emit `router.event{circuit}`; open-circuit models are ineligible (`circuit_open`).
4. **Result:** `LlmResponse` with `attempts`, `latencyMs`, `modelKey` actually used, `costMicroUsd: 0` placeholder (ledger integration in M3-02 subscribes to a `RouterCompleted` internal event carrying usage + model; emit it now on the internal bus — define `RouterCompleted` locally in `llm-router.ts`, also emitted for billed failures).
5. **Streaming API:** `dispatch(req, { onDelta, onReset, signal })`.
6. **Errors:** terminal failures map via `failureToAppError`; `LADDER_EXHAUSTED` remediation lists every attempted model + reason.
