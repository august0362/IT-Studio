# M14-02 — Facebook Page adapter: conversations sync

Milestone: M14 · Depends on: M14-01 · Role: Implementer · Size M · **Deps pre-installed**
Requirements: FR-FB-02, FR-CH-02 · ARCH §17.6

## Scope
`providers/channel/facebook/facebook-adapter.ts` (+ test, passes the channel contract suite), fixtures `apps/sidecar/test/fixtures/facebook/*.json`, adapter registration.

## Requirements
1. Cursor = ISO time of the newest `updated_time` seen. Request `/{page-id}/conversations?fields=updated_time,participants,messages.limit(20){id,message,from,created_time}&limit=25`, follow `paging.next` until conversations are older than the cursor (max 10 pages per sync).
2. Store only messages whose `from.id` ≠ Page id and `created_time` > cursor; `externalThreadId` = conversation id, `externalMessageId` = message id, `from` = `{id, name}`, no subject, text = `message` (attachments-only messages → text "[attachment]").
3. Provide `computeSendBefore(message)` = `created_time + 24 h` of the **latest customer message in that thread** (adapter hook used by `draft_reply`).
4. Rate-limit headers parsed on every response (shared helper with M14-03).
