# M11-02 — Memory filter (secrets / PII) and de-duplication rules

Milestone: M11 · Depends on: M11-00 · Role: Implementer · Size M · **Deps pre-installed**
Requirements: FR-MEM-04, FR-MEM-05, FR-MEM-11 · ARCH §16.2

## Goal
Pure, exhaustively tested rules that keep secrets and third-party contact data out of memory and merge near-duplicates.

## Scope
- `apps/sidecar/src/domain/memory-filter.ts` (+ test), `apps/sidecar/src/domain/memory-dedupe.ts` (+ test), shared secret patterns per M11-00 decision (`config/secret-patterns.json` loader or `domain/secret-patterns.ts`)

## Contracts
```ts
type FilterVerdict = { ok: true } | { ok: false; reason: 'secret' | 'third_party_contact' | 'too_long' | 'empty' };
export function filterMemoryText(text: string, ctx: { sourceKind: 'conversation' | 'channel' | 'manual'; ownerAddresses: readonly string[] }): FilterVerdict;
export function decideDedupe(candidate: { text: string; importance: 1|2|3|4|5 }, nearest: { item: MemoryItem; cosine: number } | null,
  threshold?: number /* 0.92 */): { action: 'insert' } | { action: 'merge'; text: string; importance: 1|2|3|4|5; targetId: MemoryId };
```

## Requirements
1. Secret patterns: same set as the repo secret scanner (provider keys, JWT-like tokens, private key headers, `password=`/`token=` assignments, long hex/base64 secrets ≥ 32 chars).
2. Third-party contact (channel sources only): email addresses not in `ownerAddresses`, phone numbers (E.164 and Vietnamese formats `0xxxxxxxxx`, `+84…`).
3. Empty/whitespace → `empty`; > 500 chars → `too_long` (extractor already limits to 300; manual entry may be up to 500).
4. Dedupe: cosine ≥ threshold → merge (keep the longer text; importance = max) else insert. Threshold boundary 0.92 inclusive.

## Tests
Corpus test (≥ 20 positive, ≥ 20 negative strings incl. Vietnamese text, emails of owner vs others, phone formats); dedupe at 0.9199 / 0.92 / 0.95; MC/DC-lite naming.
