# M17-03 — Container log streaming: demux, coalescing, back-pressure, auto-close

Milestone: M17 · Depends on: M17-01 · Role: Implementer · Size L · **Deps pre-installed**
Requirements: FR-DK-05, NFR-V3-04 · ARCH §20

## Scope
`services/docker/log-stream-service.ts` (+ test), `domain/log-coalescer.ts` (+ test: pure batching/drop policy), `src/types/schemas.ts` RPC `docker.logs.open|close` + notifications `docker.log`, `docker.logDropped`, `docker.logClosed`, validators, `container.ts`.

## Requirements
1. `open`: tail 1–5 000 (default 500), follow, stdout/stderr flags; max 4 open streams app-wide (5th → `VALIDATION`); returns `streamId`.
2. Demultiplex Docker 8-byte frame headers (TTY containers: raw stream → stdout); decode UTF-8 safely across chunk boundaries; split into lines.
3. Coalescer: flush every 50 ms or at 64 KB, ≤ 20 chunks/s per stream; backlog > 2 MB → drop oldest lines, emit `docker.logDropped{droppedBytes}` once per drop episode.
4. Auto-close on `close`, UI reconnect (sidecar receives no `system`-level hint → close all streams when the Rust shell restarts the sidecar is implicit; additionally close when the server disconnects or the container stops → `docker.logClosed{reason}`).
5. No log content in sidecar logs or activity events.

## Tests
Frame demux (split headers across chunks, multi-byte UTF-8 split), coalescer timing with fake timers (rate cap, size cap, drop episode), stream limits, close reasons. Load test (L2): 5 000 lines/s for 10 s → bounded memory and ≤ 20 notifications/s.
