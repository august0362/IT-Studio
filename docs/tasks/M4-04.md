## Requirements
1. **Conversations** (left column): `chat.listConversations` for the active project, newest `updatedAt` first; "New chat" → `chat.createConversation`; selecting one loads `chat.getMessages`. "All projects" tab → empty state asking to pick a project.
2. **Model picker**: options from `models.list` (only `enabled` chat-capable models), grouped by provider; first option "Auto (router ladder)" = no `modelOverride`. A "Lock" toggle sets `RouterConfig.lockedModelKey` to the selected model via `router.getConfig` → `router.updateConfig` (unlock → `null`); show a lock indicator when the config is locked.
3. **Send**: Enter sends, Shift+Enter newline, empty/whitespace-only disabled; `chat.send` → append the user message optimistically and an assistant bubble in `streaming` state keyed by `requestId`. While streaming the Send button becomes **Stop** → `chat.cancel`.
4. **Streaming reducer** (`chat-store.ts`, pure, 100 % branches): `chat.delta` appends to the bubble of its `requestId` (ignore unknown ids); `router.event{type:'fallback'}` for that id **clears the partial text** and records `{from,to,reason}`; `chat.completed` replaces the bubble with the final `ChatMessage` + `cost`; `chat.failed` marks it failed with the `AppError` (render with `ErrorPanel`, including remediation). Out-of-order events after completion are ignored.
5. **Fallback badge**: a completed message whose request fell back shows a badge "Answered by <to> (fallback from <from>: <reason>)" (i18n). Model name of every assistant message is shown.
6. **Fallback modal** (Auto Fallback OFF): on `router.fallbackRequired` open an accessible modal (focus trap, Esc = Cancel) listing candidates with estimated cost (`<Money value={estimatedCost}>`; if `estimatedCost` is absent show "—" — never format µUSD in React) and a countdown to `expiresAt`; buttons *Use* (per candidate) / *Retry same* / *Cancel* → `router.resolveFallback`; on expiry close the modal (sidecar applies the default).
7. **Cost**: each completed assistant message shows `<Money value={cost}>` (USD line 1, VND line 2).
8. **Rendering**: assistant text through `SafeMarkdown` only; user text as plain text. Auto-scroll to bottom while the user is at the bottom; preserve scroll otherwise.
9. Keyboard-only usable; all controls labelled; strings in en + vi.
