# M10-08 — Chat: agent picker, project default, run cost, tool-call cards

Milestone: M10 · Depends on: M10-03, M10-04 · Role: Implementer · Size L · **Deps pre-installed**
Requirements: FR-AG-05, FR-AG-09 (UI), FR-AG-15, FR-AG-16 (cancel button reuses chat cancel)

## Goal
In the Chat tab the owner picks which agent answers, sees which agent/model answered and what it cost, and confirms or dismisses pipeline proposals.

## Read first
SRS v2 §3.1, §6.3/§6.4, `apps/desktop/src/features/chat/**` (ModelPicker, MessageList, chat-store), `<Money>`, `<SafeMarkdown>`.

## Scope
- `apps/desktop/src/features/chat/{AgentPicker.tsx,ToolCallCard.tsx,PipelineConfirmCard.tsx}` (new) + edits to `ChatPage.tsx`, `MessageList.tsx`, `chat-store.ts`, `ConversationList.tsx` (agent badge) + tests
- Project default selector: in the chat header ("Default for this project") using `agents.getProjectDefault/setProjectDefault`
- i18n en/vi; `e2e/specs/m10/agent-chat.spec.ts` (written, not run) + wdio registration

## Requirements
1. Agent picker in the chat header (None = v1 assistant, then enabled agents); changing it calls `chat.setAgent`; when an agent is selected the model picker shows the agent's ladder read-only ("Models from agent").
2. Assistant messages show agent name + model + `<Money>` cost; run cost from `agent.run` notifications.
3. Tool cards (collapsible, plain text): `search_knowledge` (n hits, titles), `recall_memory` (n memories), `remember` (saved text), `draft_reply` (link "Open in Outbox" — disabled until M12), `start_pipeline` → `PipelineConfirmCard` with editable prompt, *Start* (calls `agents.confirmPipeline`, then navigates to Code tab run via the navigation-intent store from MW-04), *Dismiss*.
4. Agent unavailable error renders `<ErrorPanel>` with remediation and opens the picker.
5. Model text rendered only via `<SafeMarkdown>`; tool arguments never rendered as HTML.

## Tests
Component tests with fake RPC/notifications: picker change, ladder display, cost line, each card type, confirm/dismiss, error panel. E2E `TC-M10-031` (written): pick PM agent → scripted reply with `start_pipeline` → confirm card → Start → Code tab shows the run.
