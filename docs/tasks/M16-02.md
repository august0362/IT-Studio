# M16-02 — macOS metrics collector and parser

Milestone: M16 · Depends on: M16-00 · Role: Implementer · Size M · **Deps pre-installed**
Requirements: FR-MT-02, FR-MT-04, FR-MT-05 · ARCH §19.1

## Scope
`apps/sidecar/src/domain/metrics/macos.ts` (+ test), catalog entry `metrics_macos`, `services/metrics/collectors/macos-collector.ts` (+ test).

## Requirements
1. Script sections: `top -l 1 -n 0` (CPU usage line: user/sys/idle %), `sysctl -n vm.loadavg hw.memsize kern.boottime`, `vm_stat` (page size from header; used = (active + wired + compressed) × page size), `netstat -ib` (sum `Ibytes`/`Obytes` of `en*` link-level rows, deduplicated per interface), `df -kP` (exclude `devfs`, `map *`, `/System/Volumes/*` except `/System/Volumes/Data`), `pmset -g batt` (percent + state; "no batteries" → null).
2. CPU% from `top` directly (100 − idle); uptime from `kern.boottime { sec = … }`.
3. Same robustness rules as Linux (partial samples, never throw).

## Tests
macOS fixtures (laptop with battery, desktop without), synthetic edge cases.
