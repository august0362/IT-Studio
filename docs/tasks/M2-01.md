## Requirements
1. `ports/llm-provider.ts`:
   ```ts
   interface ProviderRequest { modelId: string; system?: string; messages: readonly ProviderMessage[]; tools?: readonly ToolDeclaration[];
     maxOutputTokens: number; temperature?: number; responseFormat: 'text' | 'json'; timeoutMs: number }
   type ProviderMessage = { role: 'user' | 'assistant' | 'tool'; parts: readonly ContentPart[] }   // ContentPart from schemas
   interface ProviderResponse { text: string; toolCalls: readonly ToolCall[]; usage: TokenUsage; finishReason: LlmResponse['finishReason']; providerModelId: string }
   interface ProviderFailure { kind: FailureKind; httpStatus?: number; retryAfterMs?: number; billed: boolean; message: string }
   interface ILlmProvider { readonly id: ProviderId;
     complete(req: ProviderRequest, apiKey: string, signal: AbortSignal): Promise<Result<ProviderResponse, ProviderFailure>>;
     stream(req: ProviderRequest, apiKey: string, signal: AbortSignal, onDelta: (text: string) => void): Promise<Result<ProviderResponse, ProviderFailure>>;
     listModels(apiKey: string, signal: AbortSignal): Promise<Result<readonly string[], ProviderFailure>> }
   ```
   (`apiKey` passed per call — adapters never read the secret store, D2.)
2. `domain/failure.ts`: pure helpers `parseRetryAfter(headerValue, now): number | undefined` (seconds or HTTP-date), `isFallbackTrigger(kind)` using `FALLBACK_TRIGGERS`, `failureToAppError(f, provider, model): AppError` (maps kinds → ErrorCode with remediation text per ARCH §5.2 table; message never contains raw provider body or key).
3. Contract suite `runProviderContract(name, makeProvider, fixtures)` (vitest `describe` factory) asserting for any adapter: success complete → usage numbers non-negative integers, text matches fixture; stream → deltas concatenate to final text; tool-call fixture → `toolCalls` parsed with valid JSON args and `finishReason='tool_calls'`; 429 with Retry-After → `rate_limited` + `retryAfterMs`; quota body → `quota_exhausted`; 401 → `auth`; 400 → `bad_request`; 500/503/529 → `server_error`; timeout (no first byte) → `timeout`; abort signal → rejects quickly with no further deltas; API key appears only in the auth header (assert via msw request capture) and never in returned messages.
4. `msw-harness.ts`: helpers to register JSON + SSE (`text/event-stream`) fixture responses per URL, capture requests, and simulate a stalled response for timeout tests.
5. `FakeLlmProvider` implementing the port with scripted outcomes (used by router tests in M2-06/07); it must pass the contract suite.
