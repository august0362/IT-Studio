# DX-02 — Stop Vite watching `src-tauri` (EBUSY noise in `npm run dev`)

Role: Implementer · Size XS · **Deps pre-installed**

## Problem (owner, 2026-10-16)

Running `Start-IT-Studio.bat` / `npm run dev` prints many `file watcher error: EBUSY: resource busy or locked, watch '…\apps\desktop\src-tauri\target\debug\build\…\build_script_build-….exe'` lines while Rust compiles. Vite's dev server watches `apps/desktop/**`, including the Rust build output that cargo keeps locked.

## Scope

`apps/desktop/vite.config.ts` (+ a small test if the repo has config tests), this task file.

## Requirements

- In the Vite config add `server.watch.ignored` for `**/src-tauri/**` (Tauri's recommended setting), keeping existing `server` options (`port: 1420`, `strictPort: true`).
- No other behaviour change; production build unaffected.

- [ ] `npx prettier --write <changed files>`, `npm run typecheck`, `npm run lint` pass.
