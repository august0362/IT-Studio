# M12-07 — VS Code extension: chat panel (webview)

Milestone: M12 · Depends on: M12-06 · Role: Implementer · Size L · **Deps pre-installed** (esbuild, `@vscode/vsce`, `@vscode/test-electron`)
Requirements: FR-CH-08, FR-CH-10 · ARCH §17.4

## Scope
- `apps/vscode-ext/src/chat/{chat-panel.ts,chat-protocol.ts,webview/index.ts,webview/styles.css}` (+ tests), `apps/vscode-ext/src/bridge.ts` (protocol 2 hello, chat routing), `apps/vscode-ext/package.json` (command `itstudio.openChat`, keybinding none, menu entries "IT Studio: Send selection to chat" in editor context), extension build script (bundle the webview script)
- `apps/vscode-ext/test/e2e/chat.test.ts` (written; QA runs `npm run test:vscode-e2e`)

## Requirements
1. Command "IT Studio: Open Chat" opens a `WebviewPanel` (retain context when hidden). Panel: agent picker, conversation history of this session, input (Enter sends, Shift+Enter newline), streamed reply, cost line, *Send selection*, *Send current file*, *Start pipeline* confirmation box (editable prompt, Start / Dismiss).
2. Webview CSP per FR-CH-10 with a per-load nonce; `localResourceRoots` limited to the extension `media` folder; no remote resources; messages between webview and extension validated (zod or hand-written guards — no `any`).
3. Reply rendering: markdown → HTML with `markdown-it` (pre-installed in M12-00 for `apps/vscode-ext`) configured `html: false, linkify: false`; links rendered as text + `vscode.env.openExternal` on click via a message to the extension (http/https only) — never insert raw model HTML.
4. Disconnected sidecar → panel shows "IT Studio is not connected" and disables input; reconnect re-enables.
5. Theme: VS Code theme CSS variables (`--vscode-*`) only.

## Tests
Unit: protocol guards, panel state reducer, selection/file attachment size limits. VS Code E2E `TC-M12-041` (written): open panel → send → scripted reply visible.

## Acceptance criteria
- [ ] typecheck/lint/test green; `npm run build -w itstudio-vscode` OK; vsix packs. Do not run VS Code E2E (QA runs it in a **new** VS Code window).
