2. Tree (lazy-loaded directories) + table (name with kind icon, size human, modified local time, mode `rwxr-xr-x`); sort by column; keyboard: arrows, Enter opens dir/file, Backspace goes up, F2 rename, Delete deletes (confirm).

4. Opening a text file opens the editor (M18-05); too large / binary → message with *Download* button.
5. Errors via `<ErrorPanel>`; theme tokens; en + vi.
