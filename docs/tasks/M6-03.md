# M6-03 — CommandRunner + output parsers (tsc, eslint, vitest)

Milestone: M6 · Depends on: M6-01 · Role: Implementer (ROLES §1.3) · **Deps pre-installed** · Security-relevant (D16)

## Goal
The Worker can run only allow-listed validation commands safely (`shell:false`, scrubbed env, timeout, bounded output) and turn their output into `Diagnostic[]` / `TestSummary` (ARCH §9.5).

## Read first
- `AGENTS.md`, `TESTING.md` §3–§4, `ARCHITECTURE.md` §9.5, §11 (command-injection row), `schemas.ts` §9 (`CommandSpec`, `CommandRun`, `Diagnostic`, `TestSummary`), `config/commands.default.json`, `apps/sidecar/src/domain/path-guard.ts`

## Scope
- `apps/sidecar/src/ports/process-runner.ts`, `apps/sidecar/src/infra/node-process-runner.ts` (+ test), `apps/sidecar/src/services/command-runner.ts` (+ test), `apps/sidecar/src/domain/parsers/{tsc,eslint,vitest}.ts` (+ tests with captured fixtures under `apps/sidecar/src/domain/parsers/fixtures/`)

## Requirements
1. `IProcessRunner.run({ executable, args, cwd, env, timeoutMs, signal }) → Result<{ exitCode, timedOut, durationMs, stdoutTail, stderrTail }>` using `spawn(..., { shell: false, windowsHide: true })`; stdout/stderr kept as **last 64 KB** each; timeout kills the process tree (Windows: `taskkill /PID <pid> /T /F` via `spawn` with `shell:false`).
2. Executable resolution: `"node"` → `process.execPath`; `"npm"` → `process.execPath` + `<dirname(execPath)>/node_modules/npm/bin/npm-cli.js`; anything else → rejected (`VALIDATION`). Args must be plain strings without NUL; never interpolated into a shell.
3. Env scrub: start from an allow-list (`PATH`, `SystemRoot`, `TEMP`, `TMP`, `HOME`, `USERPROFILE`, `APPDATA`, `LOCALAPPDATA`, `NODE_OPTIONS` removed) — never pass any `*_API_KEY`, `ITSTUDIO_*` secrets, or tokens.
4. `CommandRunner.run(projectRoot, CommandSpec)` → `CommandRun` (with id, parsed `diagnostics`, `tests`); `cwd` must be the real path of the project root (via path guard helpers).
5. Parsers (pure, fixture-tested): tsc (`file(line,col): error TSxxxx: msg`, relative paths normalized to `WorkspaceRelativePath`), eslint `--format json`, vitest `--reporter=json` (passed/failed/skipped + failures with names/messages/paths). Malformed output → empty diagnostics + a single `info` diagnostic noting parse failure (never throw).

## Tests
- Process runner: success, non-zero exit, timeout kills tree, output tail truncation (generate > 64 KB), env scrub (child prints env; assert no secret-looking vars), rejected executables and NUL args.
- Parsers: realistic fixtures (multi-file tsc errors, eslint warnings/errors, vitest pass/fail mix), malformed input.
