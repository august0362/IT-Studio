## Requirements
1. **Range picker** (`date-range.ts`, pure, 100 % branches): presets Today / Last 7 days / This month / Last month / All time + custom; produces UTC ISO `[from, to)`; default This month.
2. **Project view** (a project tab is active): KPI cards revenue / cost / margin (`<Money>`; margin negative → danger token) and margin % (`—` when null); charts by model (bar), by purpose (donut), by day (line) with Recharts using only `--chart-*` CSS variables (no raw colours); empty state when no data.
3. **Budgets:** bars from `budget.status` (fraction used; level `ok` / `warning` / `exceeded` shown with token colours **and** text), "Hard Stop active" badge when `blocking`; inline edit form → `budget.set`. The USD limit is typed as a decimal string and parsed to integer µUSD by a pure helper `features/cost/money-input.ts` (`usdStringToMicroUsd`) using string arithmetic only — no floats. This is input parsing, not currency formatting; all displayed money still comes from `MoneyDisplay`.
4. **Revenue form:** amount + currency (USD / VND) + description → `revenue.add`; validation messages from the sidecar error; list of entries (`revenue.list`) with `<Money>` derived from the returned entries (no client conversion).
5. **Ledger table:** `ledger.query` with filters model / purpose / range, cursor pagination ("Load more"), columns time, model, purpose, tokens in/out, cost (`<Money compact>`), billed-failure flag.
6. **Live refresh:** subscribe to `ledger.entry` and `budget.alert`; debounce 1 s, re-query the visible data only.
7. **All projects tab:** `PortfolioPage` from `pnl.getAll`: portfolio KPIs, per-project table (name, revenue, cost, margin, margin %, sorted worst margin first), top spend by project and by model.
8. Keyboard accessible; charts have a text summary / table alternative for screen readers.

## Architect decision (resolves the Blocked contract gaps)
The UI must never convert or format money, so the sidecar provides display values. **Scope extended** to: `src/types/schemas.ts` (additive only, exact shapes below), `apps/sidecar/src/validation/**`, `apps/sidecar/src/services/{ledger-service,revenue-service,budget-guard}.ts` (+ tests), `apps/sidecar/src/domain/money.ts` (+ test, parsing helper only), `apps/sidecar/src/container.ts` (3 `server.register` lines only), `apps/sidecar/test/integration/pnl.test.ts` (extend).

Schema additions (§6 next to `LedgerEntry` / `RevenueEntry`, and in `RpcMethodMap`):
```ts
export interface LedgerRow { readonly entry: LedgerEntry; readonly cost: MoneyDisplay; }
export interface RevenueRow { readonly entry: RevenueEntry; readonly amount: MoneyDisplay; }
'ledger.queryRows': { params: LedgerQuery; result: Page<LedgerRow> };
'revenue.listRows': { params: { readonly projectId: ProjectId; readonly from: IsoDateTime; readonly to: IsoDateTime }; result: readonly RevenueRow[] };
'budget.setUsd': {
  params: { readonly projectId: ProjectId; readonly period: BudgetPeriod; readonly limitUsd: string; readonly warnAt: readonly number[] };
  result: BudgetStatus;
};
```
Rules:
- `ledger.queryRows` / `revenue.listRows` = the existing query + `MoneyDisplay` built with the current effective FX (same formatter as `ledger.entry`). Existing `ledger.query` / `revenue.list` stay unchanged.
- `budget.setUsd`: `limitUsd` is a plain decimal string (`^\d+(\.\d{1,6})?$`, > 0), parsed to integer µUSD in `domain/money.ts` with string/bigint arithmetic only (no floats); invalid → `VALIDATION`; then same behaviour as `budget.set`.
- UI: use the three new methods; **delete** `features/cost/money-input.ts` and its requirement; ledger cost via `<Money compact value={row.cost}>`, revenue via `<Money value={row.amount}>`. Margin percent formatting (`toFixed`) is fine — it is not currency.
- Tests: money parser table (`"0.000001"` → 1, `"12.5"` → 12 500 000, `"1e3"`, `"-1"`, `""`, 7 decimals → rejected); service tests for the 3 methods; extend TC-M3-040 to call `revenue.listRows` and `ledger.queryRows` and check the µUSD values match the raw methods.
