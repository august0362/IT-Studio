# M4-05 — Cost & P&L tab (per project + All-projects dashboard)

Milestone: M4 · Depends on: M3-02, M3-06, M3-07, M4-01 · Role: Implementer (ROLES §1.3) · **Deps pre-installed** (`recharts` ~3.10)

## Goal
Show where the money goes and whether each project makes a profit: revenue / cost / margin, breakdowns by model, purpose and day, budgets with warning states, revenue entry in USD or VND, a filterable ledger, and a portfolio view across all projects (D6, D7, D8, D13, ARCH §6.5).

## Requirements
1. **Range picker** (`date-range.ts`, pure, 100 % branches): presets Today / Last 7 days / This month / Last month / All time + custom; produces UTC ISO `[from, to)`; default This month.
2. **Project view** (a project tab is active): KPI cards revenue / cost / margin (`<Money>`; margin negative → danger token) and margin % (`—` when null); charts by model (bar), by purpose (donut), by day (line) with Recharts using only `--chart-*` CSS variables (no raw colours); empty state when no data.
3. **Budgets:** bars from `budget.status` (fraction used; level `ok` / `warning` / `exceeded` shown with token colours **and** text), "Hard Stop active" badge when `blocking`; inline edit form → `budget.set`. The USD limit is typed as a decimal string and parsed to integer µUSD by a pure helper `features/cost/money-input.ts` (`usdStringToMicroUsd`) using string arithmetic only — no floats. This is input parsing, not currency formatting; all displayed money still comes from `MoneyDisplay`.
4. **Revenue form:** amount + currency (USD / VND) + description → `revenue.add`; validation messages from the sidecar error; list of entries (`revenue.list`) with `<Money>` derived from the returned entries (no client conversion).
5. **Ledger table:** `ledger.query` with filters model / purpose / range, cursor pagination ("Load more"), columns time, model, purpose, tokens in/out, cost (`<Money compact>`), billed-failure flag.
6. **Live refresh:** subscribe to `ledger.entry` and `budget.alert`; debounce 1 s, re-query the visible data only.
7. **All projects tab:** `PortfolioPage` from `pnl.getAll`: portfolio KPIs, per-project table (name, revenue, cost, margin, margin %, sorted worst margin first), top spend by project and by model.
8. Keyboard accessible; charts have a text summary / table alternative for screen readers.
