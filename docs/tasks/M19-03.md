# M19-03 — Guide: `docs/guides/server-setup.md`

Milestone: M19 · Depends on: M19-00 · Role: **Architect** · Size S
Requirements: FR-SA-05, A-1 (SRS v3)

## Content (English, per OS sections)
1. Generate a key on Windows (`ssh-keygen -t ed25519`), where it is stored, passphrase advice; how IT Studio stores it (encrypted, keychain data key).
2. Install the public key: Linux/macOS `~/.ssh/authorized_keys` (permissions 700/600); Windows Server OpenSSH (`administrators_authorized_keys` for admin users + ACL command).
3. Enable SSH: Ubuntu/Debian `openssh-server`; macOS *Remote Login*; Windows Server *OpenSSH Server* feature + service start + firewall rule; default shell PowerShell note.
4. Tailscale: use the MagicDNS name or `100.x` IP; Tailscale SSH is not required.
5. Verify the host fingerprint on the server (`ssh-keygen -lf /etc/ssh/ssh_host_ed25519_key.pub`; Windows `ssh-keygen -lf C:\ProgramData\ssh\ssh_host_ed25519_key.pub`) before trusting it in IT Studio.
6. Reboot/shutdown permissions: exact sudoers lines (M19-00) with `visudo -f /etc/sudoers.d/itstudio`; Windows: admin account.
7. Docker access: `docker` group (root-equivalent warning, ADR-0004), Docker Desktop on macOS/Windows; CLI ≥ 18.09 for `dial-stdio`.
8. Metrics requirements per OS (commands used; nothing installed).
9. Troubleshooting table: auth failed, host key changed, sudo required, Docker unavailable, Windows path forms.
