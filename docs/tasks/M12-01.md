# M12-01 — Channel adapter port, tables, repositories, fake adapter, contract suite

Milestone: M12 · Depends on: M12-00 · Role: Implementer · Size L · **Deps pre-installed**

## Goal
The foundation every channel builds on: one adapter interface with a shared contract test suite, persistent accounts and messages, and a scriptable fake adapter for tests and E2E.

## Contracts
```ts
interface IChannelAdapter {
  readonly kind: ChannelKind;
  sync(account: ChannelAccount, cursor: string | null, signal: AbortSignal):
    Promise<Result<{ messages: readonly Omit<ChannelMessage, 'id' | 'accountId' | 'triage' | 'summary' | 'handledByRunId'>[]; nextCursor: string | null }>>;
  send(account: ChannelAccount, item: OutboxItem, inReplyTo: ChannelMessage | null, signal: AbortSignal):
    Promise<Result<{ externalMessageId: string }>>;
  disconnect(account: ChannelAccount): Promise<Result<void>>;
}
// connect() is channel-specific (OAuth / token) and lives in each channel's service (M13-01, M14-01).
interface IChannelRepository { /* accounts CRUD, insertMessagesIgnoreDuplicates, listMessages(page), updateTriage, setHandled, cursor get/set */ }
```

## Requirements
1. `insertMessagesIgnoreDuplicates` relies on the unique `(account_id, external_message_id)` index; returns inserted count.
2. Message text: plain, max 100 000 chars, truncated with `\n[… truncated]`.
3. Contract suite asserts: sync idempotence with cursor, send returns an external id, failures return classified `AppError` (`CHANNEL_AUTH`, `CHANNEL_RATE_LIMITED`, other) — never throw.
4. Fake adapter: deterministic; script format documented in a header comment (`{ "syncs": [[{…message}], …], "send": "ok" | "fail:CHANNEL_AUTH" | "fail:CHANNEL_RATE_LIMITED" }`); only active when `ITSTUDIO_E2E=1`.
