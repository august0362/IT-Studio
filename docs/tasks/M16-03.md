# M16-03 — Windows metrics collector and parser (PowerShell, JSON)

Milestone: M16 · Depends on: M16-00 · Role: Implementer · Size M · **Deps pre-installed**
Requirements: FR-MT-03, FR-MT-04, FR-MT-05 · DD-V3-04 · ARCH §19.1

## Scope
`apps/sidecar/src/domain/metrics/windows.ts` (+ test), catalog entry `metrics_windows` (single PowerShell script, `-NoProfile -NonInteractive`, `ConvertTo-Json -Compress -Depth 4`), `services/metrics/collectors/windows-collector.ts` (+ test).

## Requirements
1. Script outputs one JSON object: `cpu` (average `Win32_Processor.LoadPercentage`), `mem` (`TotalVisibleMemorySize`, `FreePhysicalMemory` KB), `net` (sum `ReceivedBytes`/`SentBytes` of `Get-NetAdapterStatistics` for adapters with `Status -eq 'Up'`; fallback `Win32_PerfRawData_Tcpip_NetworkInterface` if the cmdlet is missing), `disks` (`Win32_LogicalDisk` DriveType=3: DeviceID, Size, FreeSpace), `battery` (`Win32_Battery`: EstimatedChargeRemaining, BatteryStatus mapping 1=discharging, 2=charging/AC, 3=full, others unknown; none → null), `boot` (`LastBootUpTime` ISO).
2. Parser zod-validates the JSON (single object vs array normalisation for one disk/adapter), computes rates via `common.ts`.
3. Mount label = drive letter (`C:`).

## Tests
Windows fixtures (Server 2019/2022, laptop with battery), single-disk object form, missing net cmdlet fallback, malformed JSON → `Result` error, sample with nulls.
