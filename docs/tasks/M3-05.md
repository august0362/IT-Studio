# M3-05 — FxService: daily USD→VND rate (no LLM), manual override

Milestone: M3 · Depends on: M3-02, M3-03 · Role: Implementer (ROLES §1.3) · **Deps pre-installed**

## Goal
`MoneyDisplay` VND amounts use a current exchange rate fetched once a day from `open.er-api.com` (plain HTTP, no tokens), with a user override (D8, CONTEXT resolved Q-03, ARCH §6.3).

## Read first

## Scope
- `apps/sidecar/src/infra/sqlite/schema.ts` (+ `fx_rates` table) + drizzle migration (**do not hand-write**; QA generates if blocked), `apps/sidecar/src/ports/fx-repository.ts`, `apps/sidecar/src/infra/sqlite/fx-repository.ts`, `apps/sidecar/src/services/fx-service.ts`, `apps/sidecar/src/scheduler/daily-job.ts`, `apps/sidecar/src/services/price-source.ts` (use FxService), `apps/sidecar/src/container.ts`, tests

## Requirements
1. Fetch `GET config.sourceUrl` via injected `IHttpClient` (timeout 10 s); read numeric `rates.VND` (path from `config.vndField`); sanity bounds 10 000 ≤ rate ≤ 100 000 and |Δ| ≤ 20 % vs last stored rate, else reject + warn log; store `FxRate{source:'auto', asOf}`.
2. Effective rate: `settings.fx.manualUsdToVnd` (if non-null) → else latest stored auto rate → else `config.seedUsdToVnd`.
3. Scheduler `daily-job.ts`: runs on sidecar start if the last auto rate is older than 24 h (and `settings.fx.autoUpdate`), then every 24 h while running; single-flight; injectable clock/timers; failures never crash the sidecar.
4. RPC `fx.get` → effective `FxRate`; `fx.override({usdToVnd: number|null})` → validates range (same bounds) or clears, persists in settings, returns effective rate.
5. All `MoneyDisplay` values built after an update use the new rate (price-source/ledger use FxService).

## Tests
- Fetch success/timeout/HTTP error/malformed JSON/out-of-bounds/Δ>20 %; precedence (manual > auto > seed); scheduler due/not-due/single-flight; override validation (9 999 / 10 000 / 100 000 / 100 001).
- Integration `TC-M3-020`: `fx.override` 25 000 → next `chat.completed` cost VND text reflects 25 000 rate (scripted provider; no network — HTTP client faked under `ITSTUDIO_E2E`).
