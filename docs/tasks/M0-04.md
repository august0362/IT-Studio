# M0-04 — Monorepo scaffold (npm workspaces, tsconfig, 3 skeleton apps)

Milestone: M0 · Depends on: M0-01, M0-02 · Role: Implementer (ROLES §1.3)

## Goal
A compiling npm-workspaces monorepo with three skeleton packages that each import a contract from `@itstudio/schemas`, and a Tauri v2 desktop shell that builds.

## Read first
- `AGENTS.md`, `CONTEXT.md` §8 (repo layout), `CONVENTIONS.md` §2 (tsconfig flags) and §5 (naming)
- `docs/decisions/ADR-0002-toolchain-pins.md` — **use exactly these version ranges; TypeScript `~6.0.3`, never 7.x**

## Scope — files you may create/modify
- `package.json`, `package-lock.json`, `tsconfig.base.json`, `tsconfig.json` (repo root)
- `apps/sidecar/**`
- `apps/desktop/**` (incl. `apps/desktop/src-tauri/**`)
- `apps/vscode-ext/**`
- Do **not** modify `src/types/schemas.ts` or any `.md` except appending `## Result` to this file.

## Requirements

### 1. Root
1. `package.json`: `"name": "it-studio"`, `"private": true`, `"type": "module"`, `"workspaces": ["apps/*"]`, `"engines": { "node": ">=24.19" }`.
   Scripts (others are added by later tasks — do not add `lint`/`test`):
   - `"typecheck": "tsc -p tsconfig.json --noEmit && npm run typecheck --workspaces --if-present"`
   - `"dev": "npm run tauri:dev -w @itstudio/desktop"`
   Root devDependency: `typescript@~6.0.3`.
2. `tsconfig.base.json` with exactly the compiler options in CONVENTIONS §2 plus `"skipLibCheck": true`, `"noEmit": true`, `"lib": ["ES2023"]`, and
   `"paths": { "@itstudio/schemas": ["./src/types/schemas.ts"] }` (paths resolve relative to this file; do **not** use `baseUrl`).
3. Root `tsconfig.json`: extends base, `include: ["src/types/**/*.ts"]` — proves schemas compile.

### 2. `apps/sidecar` (`@itstudio/sidecar`)
- `package.json` (`type: module`, private), scripts: `"typecheck": "tsc -p tsconfig.json --noEmit"`, `"dev": "tsx src/main.ts"`. Deps: `tsx@^4` (dev), `@types/node@^24` (dev).
- `tsconfig.json` extends `../../tsconfig.base.json`, `types: ["node"]`, include `src`.
- `src/main.ts`: imports `type ProviderId` and value `ProviderId` from `@itstudio/schemas`; exports `function describeSidecar(): string` returning `"itstudio-sidecar skeleton; providers=" + count`; when run directly writes that string to **stderr** (stdout is reserved for protocol, ARCH §3.1).
- `npm run dev -w @itstudio/sidecar` must run (tsx resolves the tsconfig path alias).

### 3. `apps/vscode-ext` (`@itstudio/vscode-ext`)
- `package.json`: `"name": "itstudio-vscode"`, `"publisher": "itstudio"`, `"displayName": "IT Studio Companion"`, `"engines": { "vscode": "^1.100.0" }`, `"main": "./dist/extension.js"`, `"activationEvents": ["workspaceContains:.itstudio/session.json"]`, scripts `"typecheck"`, `"build": "node build.mjs"`. Dev deps: `@types/vscode@^1.100.0`, `esbuild`, `@types/node@^24`.
- `build.mjs`: esbuild bundle `src/extension.ts` → `dist/extension.js`, `platform: node`, `format: cjs`, `external: ['vscode']`, tsconfig alias honoured.
- `src/extension.ts`: named exports `activate(context)` / `deactivate()`; activate creates a status bar item "IT Studio: idle" and pushes it to `context.subscriptions`; reference `ProviderId` from `@itstudio/schemas` in a typed constant so the alias is exercised.
- `npm run build -w @itstudio/vscode-ext` produces `dist/extension.js` (gitignored).

### 4. `apps/desktop` (`@itstudio/desktop`) — Tauri v2 + React 19 + Vite 8 + Tailwind v4
- Create files manually (no interactive scaffolder). Scripts: `"typecheck": "tsc -p tsconfig.json --noEmit"`, `"vite:dev": "vite"`, `"vite:build": "vite build"`, `"tauri": "tauri"`, `"tauri:dev": "tauri dev"`.
- Deps: `react`, `react-dom` `^19.3`, `@tauri-apps/api@^2.12`; dev: `@tauri-apps/cli@^2.12`, `vite@^8`, `@vitejs/plugin-react`, `tailwindcss@^4`, `@tailwindcss/vite`, `@types/react`, `@types/react-dom`.
- `vite.config.ts` (default export allowed here): react + tailwind plugins, `resolve.alias['@itstudio/schemas']` → absolute path of `src/types/schemas.ts`, `server: { port: 1420, strictPort: true }`, `clearScreen: false`.
- `tsconfig.json`: extends base, `lib: ["ES2023","DOM","DOM.Iterable"]`, `jsx: "react-jsx"`, include `src`, `vite.config.ts`.
- `index.html`, `src/main.tsx`, `src/App.tsx` (named export `App`), `src/index.css` (`@import "tailwindcss";`).
  `App` renders a centered heading "IT Studio" and the text "Skeleton — providers: N" where N = `Object.keys(ProviderId).length` from `@itstudio/schemas`.
- `src-tauri/`:
  - `Cargo.toml`: package `itstudio-desktop`, edition 2021, `[lib] name = "itstudio_desktop_lib"`, crate-type `["staticlib","cdylib","rlib"]`; deps `tauri = { version = "2", features = [] }`, `serde`, `serde_json`; build-dep `tauri-build = "2"`.
  - `build.rs`, `src/main.rs` (calls lib `run()`; `#![cfg_attr(not(debug_assertions), windows_subsystem = "windows")]`), `src/lib.rs` (`tauri::Builder::default().run(tauri::generate_context!())`).
  - `tauri.conf.json`: productName "IT Studio", identifier `com.itstudio.app`, version `0.1.0`, `build.devUrl: "http://localhost:1420"`, `build.frontendDist: "../dist"`, `build.beforeDevCommand: "npm run vite:dev"`, `build.beforeBuildCommand: "npm run vite:build"`, one window 1280×800 titled "IT Studio", `app.security.csp: "default-src 'self'; img-src 'self' data: asset:; style-src 'self' 'unsafe-inline'; connect-src ipc: http://ipc.localhost"`, `bundle.active: false` (packaging is M9).
  - `capabilities/default.json`: window `main`, permissions `["core:default"]` only.
  - Icons: generate with `npx tauri icon ../../src/image/theme/ColdColor.png` (run from `apps/desktop`) so `src-tauri/icons/` exists (placeholder icon).

### 5. Verify (run these yourself before finishing)
- `npm install` (repo root)
- `npm run typecheck` (root) → exit 0
- `npm run build -w @itstudio/vscode-ext` → exit 0
- `npm run vite:build -w @itstudio/desktop` → exit 0
- `cargo check --manifest-path apps/desktop/src-tauri/Cargo.toml` → exit 0
- `npx tsx apps/sidecar/src/main.ts` → prints skeleton line to stderr, nothing on stdout
