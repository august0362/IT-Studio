# M11-03 — Memory extraction service, `chat.closeConversation`, pending extraction

Milestone: M11 · Depends on: M11-01, M11-02 · Role: Implementer · Size L · **Deps pre-installed**
Requirements: FR-MEM-02, FR-MEM-03, FR-MEM-04, FR-MEM-05 · DD-V2-03 · ROLES §2.8

## Goal
When the owner switches away from or closes a conversation with an agent, durable facts/preferences/instructions are extracted with one cheap LLM call, filtered, de-duplicated and stored — never in the background without a user action.

## Read first
SRS v2 §1.5 DD-V2-03, §3.2, §6.3 (`chat.closeConversation`, `memory.extractNow`), ROLES §2.8 (prompt — implement verbatim), `services/{agent-runner,chat-service,llm-router,embedding-dispatcher}.ts`, `domain/{memory-filter,memory-dedupe}.ts`.

## Scope
- `apps/sidecar/src/prompts/memory-extractor.ts`, `services/memory-extraction-service.ts` (+ test), `services/chat-service.ts` (`closeConversation`), `services/system-service.ts` or shutdown path (mark `pending_extraction` instead of extracting), `infra/sqlite/chat-repository.ts` (pending flag + `extracted_until_message_id`), validators, `container.ts`, `src/types/schemas.ts` (RPC `chat.closeConversation`, `memory.extractNow`; notification `memory.changed`)
- Desktop: `apps/desktop/src/features/chat/chat-store.ts` + `ChatPage.tsx` — call `chat.closeConversation` when the user switches conversation, closes the project tab or leaves the Chat tab (fire-and-forget, errors shown as a toast)
- integration `apps/sidecar/test/integration/memory-extraction.test.ts`

## Requirements
1. Eligibility: conversation bound to an agent with `memory.enabled && autoExtract`; ≥ 2 user turns after `extracted_until_message_id`; turns from external triggers excluded unless `extractFromExternalChannels`.
2. One router call: model = cheapest enabled JSON-capable model (by price table input price), `purpose = memory_extraction`, `responseFormat json`, transcript capped at 12 000 tokens (newest turns kept). Output zod-validated (`{memories: [{text, kind, importance}]}` max 8); invalid → one re-ask then give up (log `warn`, no memories).
3. Each candidate → filter → embed (purpose `embedding`) → nearest same agent/scope → dedupe decision → insert/merge; scope = conversation's project (global only if the agent `shareAcrossProjects` **and** kind = `preference`).
4. Update `extracted_until_message_id`; emit `memory.changed`; Budget Hard Stop → skip silently with a `warn` log and keep `pending_extraction=1`.
5. Shutdown: do **not** call the LLM; set `pending_extraction=1` for eligible open conversations. Opening a conversation with the flag (`chat.getMessages`) or `memory.extractNow` triggers extraction (user action).
6. `memory.extractNow` returns counts `{created, updated, rejected}`.
