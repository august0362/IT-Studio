`GoogleProvider implements ILlmProvider` for the Gemini API and passes the contract suite.

## Requirements
1. Use `@google/genai` (`models.generateContent` / `generateContentStream`) with API key per call; if the SDK cannot take an `AbortSignal` or timeout, wrap with `Promise.race` + abort handling so contract abort/timeout cases pass. Base `https://generativelanguage.googleapis.com`.
2. Mapping: system → `systemInstruction`; roles `user`/`model`; tools → `functionDeclarations`; `functionCall` parts → `ToolCall` (generate stable id `call_<index>` when absent); `tool_result` → `functionResponse`; `responseFormat:'json'` → `responseMimeType: 'application/json'`.
3. Usage: `inputTokens = promptTokenCount`, `cachedInputTokens = cachedContentTokenCount ?? 0`, `outputTokens = candidatesTokenCount + (thoughtsTokenCount ?? 0)` (thinking tokens are billed as output). Finish: `STOP → stop` (or `tool_calls` when function calls present), `MAX_TOKENS → length`, `SAFETY|RECITATION|BLOCKLIST|PROHIBITED_CONTENT → content_filter`.
4. Failures: 429 / `RESOURCE_EXHAUSTED` whose message matches /per day|daily|billing|quota exceeded for quota metric.*per day/i → `quota_exhausted`, else `rate_limited` (parse `RetryInfo.retryDelay` like `"12s"` into `retryAfterMs`); 401/403 (`PERMISSION_DENIED`, `UNAUTHENTICATED`, `API_KEY_INVALID`) → `auth`; 400 `INVALID_ARGUMENT`/404 → `bad_request`; 500/503 (`UNAVAILABLE`, `INTERNAL`) → `server_error`; prompt blocked (`promptFeedback.blockReason`) → `content_filter`.
5. `listModels` → `GET /v1beta/models` → strip `models/` prefix.
6. Fixtures in Gemini wire format (JSON + SSE `alt=sse` stream). Run the contract suite.
