# M11-06 — `memory.*` RPC: list, search, edit, pin, delete, forget, export, cleanup

Milestone: M11 · Depends on: M11-01, M11-03 · Role: Implementer · Size L · **Deps pre-installed**
Requirements: FR-MEM-09, FR-MEM-11, NFR-V2-07

## Scope
- `apps/sidecar/src/services/memory-service.ts` (+ test), validators `validation/memory.ts` (+ ipc map), `container.ts`, `src/types/schemas.ts` RPC entries `memory.list|search|create|update|setPinned|delete|forgetAll|export|cleanup` (SRS v2 §6.3)
- integration `apps/sidecar/test/integration/memory.test.ts`

## Requirements
1. `list`: filters + cursor paging (newest `updatedAt` first), text search = case-insensitive substring on SQLite (no embedding cost).
2. `search`: vector search (one embedding call) with recall scoring; `topK` 1–50.
3. `create`/`update`: filter + (on text change) re-embed + dedupe against others (merge target ≠ itself); `expiresAt` must be in the future.
4. `forgetAll(agentId, confirmName)`: `confirmName` must equal the agent name exactly; deletes rows + LanceDB table; returns count.
5. `export`: JSON `{ version: 1, exportedAt, items: MemoryItem[] }` (no vectors), optionally per agent.
6. `cleanup`: purge expired, re-embed items whose embedding model ≠ current setting (batched, purpose `embedding`), `repair()`; returns counts.
7. Every mutation emits `memory.changed`. No RPC returns vectors.

## Tests
Unit per method incl. invalid confirm name, expired date in the past, merge-on-edit; integration `TC-M11-010` CRUD round trip, `TC-M11-011` forgetAll removes vectors (search returns 0), `TC-M11-012` export/cleanup counts; performance check: forgetAll + export of 10 000 items < 5 s (L3, marked slow).
