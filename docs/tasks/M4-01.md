# M4-01 — App shell: main navigation, project tabs (multi-project), i18n (en/vi)

Milestone: M4 · Depends on: M4-01b, M1-05 · Role: Implementer (ROLES §1.3) · **Deps pre-installed** (`react-i18next`, `i18next` — Architect installs before launch)

## Goal
The real application frame: left navigation for all tabs, project tabs to open several projects at once (D13), an "All projects" entry for the aggregate P&L, and English/Vietnamese UI strings.

## Read first
- `AGENTS.md`, CONTEXT D13 (multi-project), `ARCHITECTURE.md` §2.2 (startup calls), `schemas.ts` §2 (`Project`), §12 (`AppSettings.activeProjectId`, `ui.locale`), `docs/design/THEMES.md` §5 (use token classes only), existing `apps/desktop/src/App.tsx`, settings pages, `e2e/helpers/ui.ts`

## Scope
- `apps/desktop/src/App.tsx`, `apps/desktop/src/shell/**` (new: `AppShell`, `MainNav`, `ProjectTabs`, `NewProjectDialog`, router state), `apps/desktop/src/i18n/**` (new: `en.json`, `vi.json`, setup), `apps/desktop/src/state/**` (open-projects store), existing pages only to move them under the new shell, `e2e/helpers/ui.ts` + `e2e/specs/m4/shell.spec.ts` (new), `e2e/wdio.conf.ts` (register the new spec before shutdown)

## Requirements
1. Main nav (keyboard accessible, `nav[aria-label="Main navigation"]`): Chat, Code, Knowledge, Gallery (disabled "coming soon"), Cost & P&L, Settings (sub-pages: API Keys, Theme). Placeholder pages for Chat/Code/Knowledge/Cost (filled in later tasks) with an empty-state message. Keep stable `href`s: `#chat`, `#code`, `#knowledge`, `#cost`, `#settings-api-keys`, `#settings-theme`.
2. Project tabs: list from `project.list`; open/close tabs (open set persisted in `localStorage` with try/catch), active tab ↔ `project.setActive`; "+" opens `NewProjectDialog` (name + folder path text input — native folder picker comes later) → `project.create`, errors via `<ErrorPanel>`; an "All projects" pseudo-tab selects the aggregate view (used by Cost & P&L).
3. i18n: `react-i18next` with `en` (default) and `vi`; language switch in Settings → Appearance area of the Theme page (writes `settings.ui.locale`); all new strings via `t()`; translate existing visible strings of the shell, nav, API Keys and Theme pages.
4. Status bar stays at the bottom; layout uses theme tokens only.

## Tests
- Component: nav keyboard order, tab open/close/activate calls RPC, new-project validation errors shown, locale switch re-renders strings, localStorage failure tolerated.
- E2E `TC-M4-010` create a project via dialog → tab appears & active; `TC-M4-011` switch locale to vi → nav labels in Vietnamese and persisted after restart. Update E2E helpers for any changed selectors and make sure **all M1 E2E specs still pass** (QA runs full E2E).
