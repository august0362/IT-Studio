# M15-04 — Host-key TOFU, OS detection, remote command catalog

Milestone: M15 · Depends on: M15-03 · Role: Implementer · Size M · **Deps pre-installed**

## Scope
- `apps/sidecar/src/domain/host-key.ts` (+ test: fingerprint format, compare), `apps/sidecar/src/domain/remote-commands.ts` (+ test: typed catalog), `services/ssh/host-key-service.ts` (+ test), `services/ssh/os-detector.ts` (+ test), manager wiring (`hostVerifier` callback), `src/types/schemas.ts` RPC `server.confirmHostKey`, `server.trustNewHostKey` + notification `server.hostKeyPrompt`, validators, remediation `HOST_KEY_UNCONFIRMED`, `HOST_KEY_MISMATCH`
- integration `apps/sidecar/test/integration/ssh-hostkey.test.ts`

## Requirements
1. Fingerprint = `SHA256:` + base64 (no padding) of the raw host key blob (matches `ssh-keygen -lf`).
2. `hostVerifier` (ssh2 async verifier): pinned & equal → accept; none pinned → emit `server.hostKeyPrompt{firstSeen:true}` and wait for `confirmHostKey` (accept → pin fingerprint + key type, continue; reject/120 s timeout → abort `HOST_KEY_UNCONFIRMED`); pinned & different → abort immediately, state `host_key_mismatch`, prompt `{firstSeen:false, previousFingerprint}` (informational); `trustNewHostKey(fingerprint, confirmName)` requires exact server name and the fingerprint equal to the one last presented, then re-pins and reconnects.
3. No authentication attempt or command happens before the verifier accepts (NFR-V3-06 — fake server records auth attempts).
4. Catalog: `RemoteCommand` = branded constant; entries per OS: `detect_uname` (`uname -s`), `detect_windows` (`powershell -NoProfile -NonInteractive -Command "$PSVersionTable.OS"`), metrics scripts (filled in M16), reboot/shutdown (M19), docker version probe (M17). Static test: no entry contains `${`, backticks (except PowerShell escape inside constant text explicitly whitelisted), or is built by concatenation at runtime.
5. OS detection after first `online`: try `uname -s` (Linux/Darwin) else Windows probe else `unknown`; persist `os` unless the user overrode it.

## Tests
Fingerprint vectors; verifier paths (first seen accept/reject/timeout, equal, mismatch → no auth attempt); trustNewHostKey wrong name / wrong fingerprint; OS detection with scripted outputs; catalog static test.
