4. Web chat UI: the picker/grid handles 15 entries (scroll or wrap; no overflow), with the existing icon/initial fallback for sites without an icon.
5. Settings search index (OWNER-FB3 `settings-sections.ts`, if present) gains keywords for the new names under Web chat.
