# M2-03 — OpenAI-compatible provider adapter (OpenAI, xAI, Groq, Together)

Milestone: M2 · Depends on: M2-01 · Role: Implementer (ROLES §1.3) · **Deps pre-installed** (`openai`)

## Goal
One adapter class, configured per provider (`baseURL`), implements `ILlmProvider` for every OpenAI-compatible API and passes the contract suite for each (D15).

## Requirements
1. `class OpenAiCompatibleProvider` constructed with `{ id: ProviderId; baseURL: string }`. Registry constants: openai `https://api.openai.com/v1`, xai `https://api.x.ai/v1`, groq `https://api.groq.com/openai/v1`, together `https://api.together.xyz/v1`. Use the `openai` SDK Chat Completions API, client per call with `apiKey`, `maxRetries: 0`, `timeout`, `signal`.
2. Mapping: system → `{role:'system'}` (use `developer` role for OpenAI reasoning models is **not** required); tools → `tools[{type:'function', function:{name, description, parameters}}]`; `tool_calls` → `ToolCall` (parse `arguments` JSON; invalid JSON → `bad_request` failure); `responseFormat:'json'` → `response_format: {type:'json_object'}`; `max_tokens` → send as `max_completion_tokens` for `openai`, `max_tokens` for others.
3. Streaming with `stream_options: { include_usage: true }`; accumulate tool-call deltas by index.
4. Usage: `inputTokens = prompt_tokens`, `cachedInputTokens = prompt_tokens_details.cached_tokens ?? 0`, `outputTokens = completion_tokens`. Finish: `stop → stop`, `length → length`, `tool_calls|function_call → tool_calls`, `content_filter → content_filter`.
5. Failures: 429 with `error.code`/`type` `insufficient_quota` (or message /quota|billing/i) → `quota_exhausted`; other 429 → `rate_limited` (+ `retry-after` / `retry-after-ms` headers); 401/403 → `auth`; 400/404/422 → `bad_request`; 5xx → `server_error`; timeout / network / mid-stream as in M2-02.
6. `listModels` → `GET {baseURL}/models`.
7. Fixtures in OpenAI wire format (JSON + SSE `data:` lines ending `data: [DONE]`). Run the contract suite for `openai` and `groq` (same fixtures, different base URL) at minimum.
