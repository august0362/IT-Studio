- **No container wiring, no RPC, no schema change** (M8-03 wires the tool).

## Requirements
1. `IImageProvider { id; generate(req, signal): Promise<Result<GeneratedImage[]>> }` with sidecar-internal `GeneratedImage { bytes: Uint8Array; mimeType; revisedPrompt? }`.
2. DALL·E 3 via the `openai` SDK (`response_format: b64_json`, sizes allowed by the model; `count` via sequential calls because DALL·E 3 returns one image); FLUX Together (synchronous REST); FLUX Replicate (create prediction → poll every 1 s until `succeeded` / `failed`, timeout 120 s, cancellable by `signal`). Download image bytes immediately (remote URLs expire).
3. Failure classification identical to the LLM providers (`rate_limited`, `quota_exhausted`, `auth`, `server_error`, `timeout`, `content_filtered`, `invalid_request`) so the M8-03 fallback ladder can reuse it.
4. `midjourney-proxy` compiles and implements the port but always returns `VALIDATION` "disabled — requires an ADR and user consent (ToS)".
5. Keys only from the secret store; never logged.

## Tests
Fake HTTP / fake SDK: success (bytes, mime, revised prompt), each failure kind, Replicate polling success / failure / timeout / cancel, oversize response guard (> 20 MB rejected). Shared contract test for all enabled adapters. No real network.
