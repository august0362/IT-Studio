## Scope

## Contracts
Constant script printing delimited sections (`@@SECTION <name>` lines) for: `/proc/stat` first `cpu` line, `/proc/loadavg`, `/proc/meminfo`, `/proc/net/dev`, `df -kP -x tmpfs -x devtmpfs -x overlay -x squashfs`, battery (`for b in /sys/class/power_supply/BAT*; do cat $b/capacity $b/status; done 2>/dev/null`), `/proc/uptime`. Parser:
```ts
export function parseLinux(output: string, prev: LinuxRaw | null, at: IsoDateTime, serverId: ServerId):
  Result<{ sample: ServerMetricsSample; raw: LinuxRaw }>;
```

## Requirements
1. CPU% = busy delta / total delta × 100 (busy = total − idle − iowait), clamped 0–100; first sample 0.
2. Memory used = MemTotal − MemAvailable (fallback MemFree + Buffers + Cached when MemAvailable missing).
3. Network: sum rx/tx bytes of interfaces except `lo`, `docker*`, `veth*`, `br-*`, `virbr*`; rate = delta / seconds since prev; counter decrease → 0.
4. Disks: max 8 by total size; bytes from KB blocks.
5. Battery: first BAT* found; status mapping Charging/Discharging/Full/Not charging/Unknown; none → `null`.
6. Missing/garbled section → that field null/0 with a `warnings` entry in the debug log; never throw.

## Tests
All Linux fixtures from M16-00 (golden samples), synthetic edge cases (no battery, counter wrap, missing MemAvailable, empty df), performance: parse ≤ 5 ms per fixture (bench test with a generous CI bound).
