## Requirements
1. Model:
   ```ts
   interface MachineContext { candidates: readonly ModelKey[]; index: number; retries: number; maxRetries: (m: ModelKey) => number;
     autoFallback: boolean; failedModels: readonly ModelKey[] }
   type MachineInput =
     | { type: 'start' } | { type: 'budget_ok' } | { type: 'budget_blocked' }
     | { type: 'first_token' } | { type: 'completed' }
     | { type: 'failed'; failure: { kind: FailureKind; retryAfterMs?: number } }
     | { type: 'retry_timer_elapsed' } | { type: 'user_decision'; decision: FallbackDecision['action']; modelKey?: ModelKey }
     | { type: 'user_timeout' } | { type: 'cancel' }
   type MachineEffect =
     | { type: 'check_budget' } | { type: 'dispatch'; model: ModelKey } | { type: 'wait'; ms: number }
     | { type: 'emit_fallback'; from: ModelKey; to: ModelKey; reason: FailureKind }
     | { type: 'request_user_decision'; failed: ModelKey; reason: FailureKind; candidates: readonly ModelKey[] }
     | { type: 'discard_partial' } | { type: 'finish'; outcome: 'succeeded' | 'failed' | 'cancelled'; error?: ErrorCode }
   function transition(state: RouterState, ctx: MachineContext, input: MachineInput): { state: RouterState; ctx: MachineContext; effects: readonly MachineEffect[] }
   ```
2. Rules exactly per ARCH §5.2/§5.3: retry same model only for retryable kinds (`rate_limited` with retryAfter ≤ 10 s, `server_error`, `timeout`) while `retries < maxRetries`; `quota_exhausted` never retries; non-fallback kinds (`auth`, `bad_request`, `content_filtered`) → FAILED with mapped ErrorCode; fallback picks next index not in `failedModels`; none left → FAILED `LADDER_EXHAUSTED`; `autoFallback=false` → AWAITING_USER with remaining candidates; `user_decision` `use_model` must be one of the remaining candidates (else ignored), `retry_same` resets retries, `abort`/`user_timeout` → FAILED `FALLBACK_DECLINED`; failure during STREAMING emits `discard_partial` before fallback; `cancel` from any non-terminal → CANCELLED; any input in a terminal state is a no-op (returns same state, no effects); illegal transitions return the same state with no effects (and are listed in a `ILLEGAL` table used by tests).
3. `backoff.ts`: `retryDelayMs(attempt, retryAfterMs, random)` = `min(retryAfterMs ?? 500·2^attempt, 10000)` × (0.8..1.2 jitter from injected `random`).
