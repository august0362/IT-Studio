## Requirements
1. `<Money value={MoneyDisplay} compact? />`: USD text on line 1 (primary), VND text on line 2 (muted, smaller); `compact` renders one line `USD · VND`; negative values use the `danger` status style; `aria-label` reads both amounts; no number formatting in React (strings come from the sidecar).
2. `<SafeMarkdown source={string} />`: `react-markdown` + `remark-gfm` + `rehype-sanitize` (default schema, **no raw HTML**); links: only `http`, `https`, `mailto` (others rendered as text), `rel="noopener noreferrer" target="_blank"`; images disabled in v1 (render alt text); code blocks styled; never uses `dangerouslySetInnerHTML`.
3. XSS corpus (≥ 30 payloads: `<script>`, `<img onerror>`, `javascript:` links, `data:` URLs, SVG/MathML, HTML entities, markdown link/image tricks, autolinks, nested encodings) → test asserts the rendered DOM contains **no** `script`/`iframe`/`object`/`embed` elements, no `on*` attributes, no `javascript:`/`data:` hrefs.
4. `<ErrorPanel error={AppError} onRetry? />`: `role="alert"`, message + numbered remediation list, Retry button when `retryable && onRetry`; error code shown in small muted text.
5. Accessibility: semantic elements, keyboard reachable links/buttons.
