## Requirements
1. Drawer (side panel, focus-trapped, Esc closes): header with server name + Docker availability; when unavailable show `<ErrorPanel>` remediation.
2. Table: name, image, ports (`host→container/proto`), state chip (icon + text), status; filter running/all; refresh on `docker.changed` (debounced 300 ms); `docker.watch` while open.
3. Actions: Start (stopped), Stop / Restart (running) — confirmation dialog when the container publishes host ports ("This may interrupt a service on port …"); buttons disabled during the action; errors inline.
4. *Logs* opens the log viewer (M17-05) in the drawer.

## Tests
Component tests with fake RPC: table mapping, filters, confirmation rules (with/without ports), unavailable state, live refresh.
