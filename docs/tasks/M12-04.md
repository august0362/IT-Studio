# M12-04 — Triage service and *Process* (routing → AgentRunner with external restrictions)

Milestone: M12 · Depends on: M12-02, M12-03 · Role: Implementer · Size M · **Deps pre-installed**
Requirements: FR-CH-05, FR-CH-06, NFR-V2-02, NFR-V2-04 · ROLES §2.9

## Scope
- `apps/sidecar/src/prompts/triage.ts` (verbatim ROLES §2.9), `services/triage-service.ts` (+ test), `services/channel-service.ts` (`process`), `services/agent-runner.ts` (external input wrapping), validators, `container.ts`, `src/types/schemas.ts` RPC `channels.triage|applyTriage|process`
- integration `apps/sidecar/test/integration/triage-process.test.ts` + injection corpus fixture `apps/sidecar/test/fixtures/injection/*.txt` (≥ 15 cases)

## Requirements
1. `triage(accountId | messageIds)`: untriaged messages (max 100 per call), batches of 20 → one router call each (cheapest JSON model, purpose `triage`, project = account project). Output validated; ids not in the batch ignored; `command` only allowed when the message is a command candidate (Gmail sets `meta.commandCheck.isCommand`; others never) else coerced to `action`. Returns proposals; **nothing persisted**.
2. `applyTriage(results)`: persists triage + summary (≤ 25 words, plain text); emits `channels.synced` (count 0) to refresh UI; Gmail label hook (M13-04) called here via an optional adapter capability `applyLabels`.
3. `process(messageId, agentId?)`: agent = explicit → routing `resolveAgent` → else `VALIDATION` "Choose an agent" (UI then asks). Starts `AgentRunner.run` with `trigger {kind:'channel_action', channelMessageId}`, input = the message wrapped as `<context name="inbound_message" source="external">from/subject/text</context>` plus an instruction to draft a reply with `draft_reply` if a reply is appropriate; sets `handledByRunId`.
4. External runs: tool set per policy; memory extraction off unless the agent allows it; never `start_pipeline`/`remember`.

## Tests
Unit: batching (0/1/20/21 messages), command coercion, invalid model output; process agent resolution order. Integration `TC-M12-020` triage proposal → apply; `TC-M12-021` process → outbox item pending, no send; `TC-M12-022` injection corpus: for each case assert no send, no non-allowed tool executed, no memory written, no pipeline run.
