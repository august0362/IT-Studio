# M5-02 — Chunker (pure domain)

Milestone: M5 · Depends on: schemas.ts only · Role: Implementer (ROLES §1.3) · **Deps pre-installed** (no new packages)

## Goal
A pure, deterministic chunker that splits parsed documents into retrieval-sized chunks with heading/symbol context, ready for embedding (ARCH §7.1).

## Read first
- `AGENTS.md`, `CONTEXT.md`, `CONVENTIONS.md` §2, §3, §6, `ARCHITECTURE.md` §7.1, `schemas.ts` §7 (`Chunk`, `ChunkingConfig`, `DocumentFormat`)

## Scope — files you may create/modify
- `apps/sidecar/src/domain/chunker.ts`, `apps/sidecar/src/domain/chunker.test.ts`, `apps/sidecar/src/domain/token-estimate.ts` (+ test)

## Requirements
1. `estimateTokens(text): number` = `ceil(chars / 4)` for Latin text; count each CJK character as 1 token; Vietnamese (Latin with diacritics) uses the chars/4 rule. Pure, documented.
2. `chunkDocument(input: { text: string; format: DocumentFormat; config: ChunkingConfig }): readonly DraftChunk[]` where `DraftChunk = { ordinal: number; text: string; tokenCount: number; sectionPath: readonly string[] }` (define locally; the service later adds ids/embedding).
3. **Markdown / HTML-as-text / DOCX-as-text:** split on headings (`#`..`######`) when `respectHeadings`; `sectionPath` = heading trail; sections larger than `targetTokens` split on paragraph → sentence boundaries; never split inside fenced code blocks unless a single block exceeds 2× target (then split by lines).
4. **Code:** split by top-level declarations when detectable by simple regex (function/class/export/def/fn) else by line windows; `sectionPath` = `[symbolName]` when known; never cut a line in half.
5. **Text / PDF-as-text:** paragraph → sentence → hard wrap at target.
6. **Overlap:** consecutive chunks inside the same section share ≈ `overlapTokens` of trailing text (sentence/line aligned).
7. Normalise whitespace (collapse > 2 blank lines), drop empty chunks, keep ordinals contiguous from 0. Deterministic: same input → same output.
8. Performance: 5 MB markdown chunks in < 1 s on this machine (add a test with a generated document, generous timeout).

## Tests
- Heading trail correctness (nested headings), code-fence integrity, overlap size bounds, no chunk > 1.5× target except unsplittable single lines, CJK/Vietnamese token estimates, code splitting by symbols, determinism, empty input → [].
- Property test (vitest + simple random generator, no new deps): concatenation of chunks without overlap covers all non-whitespace content in order.
