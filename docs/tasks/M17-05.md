# M17-05 — Virtualised log viewer

Milestone: M17 · Depends on: M17-03 (M17-04 to embed) · Role: Implementer · Size M · **Deps pre-installed** (`react-virtuoso`, dialog plugin)
Requirements: FR-DK-07, NFR-V3-04

## Scope
`apps/desktop/src/features/servers/containers/{LogViewer.tsx,log-buffer.ts,useLogStream.ts}` (+ tests), i18n en/vi.

## Requirements
1. `useLogStream` opens on mount (`docker.logs.open`), closes on unmount; reopens on demand after `docker.logClosed`.
2. `log-buffer.ts` (pure): append chunks, split lines, keep ≤ 50 000 lines (drop oldest), stream tag per line, filter (case-insensitive substring) and stdout/stderr toggles computed lazily.
3. `react-virtuoso` list; auto-scroll toggle (on by default; turns off when the user scrolls up, button "Jump to latest"); dropped-lines banner on `docker.logDropped`.
4. *Copy visible lines* to the clipboard (max 50 000 lines). Saving to a file is deliberately not offered: the webview has no file-system plugin and adding one only for this is not justified (SRS v3 FR-DK-07, decision recorded there).
5. Monospace font from theme tokens; stderr lines visually marked with an icon + `danger` token (not colour only).

## Tests
Buffer: cap, filter, toggles, multi-chunk partial lines; component: auto-scroll behaviour, dropped banner, copy action. Performance test (L2/jsdom proxy): appending 5 000 lines per 100 ms batch keeps buffer operations < 5 ms.
