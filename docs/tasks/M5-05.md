## Requirements
1. `rag.ingest({projectId, paths, tags?})` returns an `IngestJob` (status `queued`) immediately and runs asynchronously. Unknown project → `NOT_FOUND`. Every path must resolve inside the project's workspace root via `resolveSafe` (else `VALIDATION`, nothing queued). Jobs run one at a time per project (FIFO); different projects may run in parallel.
2. Discovery (`discover-files.ts`, pure over `IFileSystem`): files and folders (recursive), extension allow-list = formats `detectFormat` accepts, size ≤ 20 MB, skip `.git`, `node_modules`, `.itstudio`, `dist`, `build`, `target`, symlinks not followed; deterministic order (sorted by path); de-duplicate.
3. Per file: parse → sha256 of the parsed text → if a `documents` row exists with the same hash **and** the same embedding model → skip (counts as processed). Else chunk (`settings.rag.chunking`) → embed in batches of `settings.rag.embedding.batchSize` via `EmbeddingDispatcher` (purpose `embedding`) → `vectorStore.deleteByDocument` then `upsertChunks` into table `chunks_<projectId>` → upsert the `documents` row (keep the same `DocumentId` when re-indexing a path).
4. Failure isolation: a failing file is logged with its error and the job continues; job ends `indexed` if ≥ 1 file succeeded or was skipped, `failed` (with the first `AppError`) only if every file failed; zero files discovered → `indexed` with `totalFiles = 0`. Budget Hard Stop (`BUDGET_HARD_STOP`) aborts the remaining files of the job → `failed`.
5. Publish `rag.progress` (`IngestJob` snapshot) when the job starts, after every file, and at the end. `processedFiles`/`totalFiles` exact; `cost` = sum of embedding cost of this job (µUSD).
6. Ledger: each successful embedding call → one ledger row with `purpose = 'embedding'` and the project id (reuse the ledger recording path the router uses; no new money math).
7. `rag.listDocuments({projectId})` → documents ordered by title. `rag.deleteDocument({documentId})` → delete vectors then the row; `{deleted:false}` if unknown.
8. Embedding model change (§7.3): if the configured model's `dimensions` differs from the stored documents' model dimension, the next ingest of the project re-embeds every document of that project (drop the table first). Unit-tested; no UI here.
9. `ITSTUDIO_E2E=1`: use `FakeEmbeddingProvider` (vector = deterministic hash-based unit vector of `settings.rag.embedding.dimensions`) instead of real providers; no network.
