# M10-02 — Agent tool policy (pure) and agent tool registry

Milestone: M10 · Depends on: M10-00 · Role: Implementer · Size M · **Deps pre-installed**
Requirements: FR-AG-07, FR-AG-08 · SRS v2 §7.4 (decision table)

## Goal
A single, fully tested place decides which tools an agent run may use and how a tool call is validated and dispatched, so prompt-injected tool calls can never execute.

## Read first
`AGENTS.md`, SRS v2 §3.1, §6.2, §7.4, ARCH §15.2, `schemas.ts` §4 (tools), §14, `services/chat-service.ts` (existing `generate_image` / `search_knowledge` declarations and dispatch), `services/rag/retriever.ts`.

## Scope
- `apps/sidecar/src/domain/agent-tool-policy.ts` (+ test)
- `apps/sidecar/src/services/agent-tools/{tool-registry.ts,search-knowledge-tool.ts,declarations.ts}` (+ tests)
- `apps/sidecar/src/ports/agent-tool.ts`

## Contracts
```ts
type RunTrigger = AgentRun['trigger']['kind'];   // 'ui' | 'vscode' | 'channel_action'
// domain
export function allowedTools(agentTools: readonly AgentToolName[], trigger: RunTrigger,
  ctx: { imageEnabled: boolean; hasChannelMessage: boolean }): readonly AgentToolName[];
export function checkToolCall(name: string, allowed: readonly AgentToolName[]): Result<AgentToolName>; // TOOL_NOT_ALLOWED
// port
interface IAgentTool<A> {
  readonly name: AgentToolName;
  readonly declaration: ToolDeclaration;              // JSON schema subset (ToolParameterSchema)
  parseArgs(raw: JsonObject): Result<A>;              // zod; VALIDATION
  execute(args: A, ctx: AgentToolContext, signal: AbortSignal): Promise<Result<JsonValue>>;
}
interface AgentToolContext { readonly runId: AgentRunId; readonly agent: AgentDefinition; readonly projectId: ProjectId;
  readonly conversationId: ConversationId | null; readonly trigger: RunTrigger; readonly channelMessageId?: ChannelMessageId }
```

## Requirements
1. `allowedTools` implements SRS §7.4 exactly (intersection with the agent's tools; `generate_image` only if `imageEnabled` and trigger ≠ external; `draft_reply` for `ui` only if `hasChannelMessage`; external triggers ⊆ {search_knowledge, recall_memory, draft_reply}).
2. `ToolRegistry` holds `IAgentTool` instances; tools not yet implemented (`recall_memory`, `remember`, `draft_reply`, `start_pipeline`) are registered as **unavailable stubs** returning `tool_result{isError:true, content:{error:'TOOL_NOT_AVAILABLE_YET'}}` — real ones arrive in M10-04, M11-04, M11-05, M12-03.
3. `search_knowledge` tool wraps the existing retriever (topK default 6, max 20); result = hits with `[n]` labels, document title, sectionPath, text truncated to 1 500 chars each.
4. Declarations reuse existing ones where present (no duplicate definitions); names/descriptions in English.
5. Log every rejected tool call at `warn` with run id, tool name, trigger (no arguments).

## Tests
Decision table test covering every cell of SRS §7.4 plus `imageEnabled` false/true and `hasChannelMessage` false/true (MC/DC-lite names). Registry: parse errors, unknown tool, stub results, search tool with a fake retriever.
