# M11-05 — Explicit remember: phrase, message action, `remember` tool

Milestone: M11 · Depends on: M11-01, M11-02 · Role: Implementer · Size M · **Deps pre-installed**
Requirements: FR-MEM-08 · DD-V2-09

## Goal
The owner can make an agent remember something on purpose — by saying so (English or Vietnamese), by clicking *Remember* on a message, or by the agent's `remember` tool — at the cost of embeddings only.

## Scope
- `apps/sidecar/src/domain/remember-phrase.ts` (+ test), `services/memory-write-service.ts` (+ test; shared by tool, phrase, message action, manual create), `services/agent-tools/remember-tool.ts` (+ test, replaces stub), `services/chat-service.ts` (phrase hook before the agent turn), `src/types/schemas.ts` RPC `memory.rememberMessage` + validator, `container.ts`
- Desktop: *Remember* action in the message menu (`features/chat/MessageList.tsx`) for user and assistant messages of agent-bound conversations; toast with "Edit in Memory"

## Requirements
1. Phrase detection at message start, case-insensitive, after trimming: `remember that `, `remember: `, `remember `, `hãy nhớ rằng `, `hãy nhớ `, `nhớ rằng ` → remainder is the memory text; message still goes to the agent (the agent sees it was saved: system note "Saved to memory").
2. Kind: `instruction` if the text starts with an imperative cue (`always`, `never`, `luôn`, `đừng`, `không được`, `please`) else `fact`; importance 3.
3. All writes pass `filterMemoryText` (source `conversation`/`manual`) and dedupe; rejection returns `VALIDATION` with the reason (UI toast).
4. `remember` tool allowed only for non-external triggers (policy already), with `RememberArgs`.
5. `memory.rememberMessage(messageId)` uses the message text (first 500 chars; tool/citation parts ignored).

## Tests
Phrase table (en/vi, mid-sentence not matched, empty remainder rejected), kind inference, filter rejection path, tool + RPC; component test for the message action.
